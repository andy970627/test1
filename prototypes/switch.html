試驗場・城區地圖

由西往東：從木馬肚子裡出發，穿過廣場和窄巷，走到城門。每個試驗場掛在它所在的區。

  1. 第 0 區

    開場

    從這裡玩整關 →

    故事字卡與設定，沒有試驗場。

  2. 第 1 區

    木馬腹中

    從這一區玩整關 →
    • 腹中練習站定後的第一步有沒有踩在鼓點上
  3. 第 2 區

    神殿廣場

    從這一區玩整關 →
    • 木馬共鳴＋敲暗號T 跟著拍敲，三下＝引開、兩下＝現在；共鳴隨距離變小
    • 跑Shift 按住跑：只有最響的一擊蓋得住
    • 查看N／M 製造聲響、V 彈弓弦，讓走過來查看的衛兵找不到你
    • 追殺聽追兵的腳步，躲開他的搜索
    • 越來越急（DRIVE）0～8 切段、K 假裝追殺：聽鼓怎麼一路變急
    • 最響一擊照亮場景那一擊照出衛兵輪廓（整關版勾上面「照亮場景版」）
    • 走法（比三種）
    • P0 現狀按住滑著走
    • P1 步子跟著鼓按住走，一步落在一個鼓點
    • P2 圈內自己踩靠近衛兵時一步按一下
  4. 第 3 區

    城牆下的窄巷

    從這一區玩整關 →
    • 蹲Alt 按住蹲：慢但輕，矮東西擋得住視線
    • 屏息聽空白鍵 按住：聽衛兵從哪個方向來
  5. 第 4 區

    城門

    從這一區玩整關 →

    推門閂（E 按住），整關最後一段；沒有單獨的試驗場。
