# 遊戲內文字校正表

## 0. 風格規則（使用者 2026-10-13 選定）

| 項目 | 規則 |
|---|---|
| 口吻 | **敘事**（開場、過場、死因、結局、筆記）用說書人第三人稱：「奧德修斯……」；**提示**（操作、情境提示、選單）用第二人稱或不用人稱 |
| 用詞 | 白話為主，少量史詩稱號（「波塞頓之子」）；不用文言、不堆形容詞 |
| 操作提示 | 按鍵在前、只寫動作：「E 推・Shift＋E 猛推」「右鍵 塞石子當楔子（按住 拔回）」 |
| 情境提示 | **只描述發生了什麼**，不教怎麼做（讓玩家自己想）；怎麼做寫在筆記裡 |
| 巨人稱呼 | 提示裡用「巨人」或「他」；開場、結局、筆記等史詩場合用「波呂斐摩斯」或「波塞頓之子」 |
| 標點 | 情境提示不用破折號；一句話不加句號，兩句以上用句號分開 |

用法：「新風格建議」是我照上面規則改寫的版本。同意就不用動；想改的填在「改成」欄。`{X}` 這類大括號會換成數字，請保留。
