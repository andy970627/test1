# 網頁介面設計系統（2026-11-15，總控，草案）

> [!IMPORTANT]
> 要你選：整體方向 A／B／C（第 5 節）。選定後由畫面角色照本文件改所有頁面。

狀態：🟡 草案，等使用者選方向。
一句話結論：**介面的顏色就是遊戲裡的訊號**（踩得上的拍、衛兵巡邏／查看／追殺、最響一擊），玩家在選單、試驗場、試聽頁學到的顏色，進遊戲就認得；唯一的大膽元素是一條貫穿所有頁面的「拍帶」。
依據：使用者 11/15「整個系統設計優化」（frontend-design 技能）、11/15 美術方向（插圖二次元、3D 暗色寫實）、Unity《雙盲洞穴》共用調色盤 `Assets/Odyssey/OdysseyPalette.cs`（羊皮紙、金、回紋金、血紅）、現有網頁字型（Noto Serif TC 題字＋Noto Sans TC）。
範圍：`prototypes/index.html`（總首頁）、`switch.html`（切換台）、`troy-prologue/index.html`（開場、選單、試驗場面板、提示）、`audio-test.html`（試聽頁）、`playtest-*.html`（試玩清單）。不動 3D 場景本身。
專有詞：**設計代號（token）**＝把顏色、字級取名字集中管理，各頁都用同一組名字，改一處全站一起變；**拍帶**＝畫面上一條從右往左滑的拍點列，碰到中線就是一拍（敲暗號試驗場已經有）。

---

## 1. 這是什麼、給誰、要做到什麼

- **主題**：特洛伊城的夜，木馬裡的人靠鼓聲潛行。青銅時代、火把、月光、城牆石。
- **讀者**：老師與同學（第一次看、要 10 秒看懂怎麼玩）、組員（找試驗場與試玩清單）、使用者本人（每天切換試驗場）。電腦螢幕為主。
- **主要工作**：讓人很快找到要試的東西、看懂按鍵、看懂畫面上的數字代表什麼。

## 2. 顏色（6 個，全部有遊戲意義）

| 代號 | 色碼 | 名稱 | 只用在 | 遊戲裡對應 |
|---|---|---|---|---|
| `--night` | `#0E1322` | 夜空墨 | 頁面底 | 月光下的城（帶藍，不用中性黑） |
| `--stone` | `#232838` | 城牆石 | 面板、區塊底 | 城牆、石板路 |
| `--parchment` | `#F2ECDD` | 羊皮紙 | 內文、標題 | 沿用洞穴篇 Parchment |
| `--bronze` | `#C9A55C` | 青銅 | 可以按的東西（連結、按鈕、目前選中） | 沿用洞穴篇 Gold；青銅時代的器物 |
| `--beat` | `#6FB3A6` | 海青 | 踩得上的拍、準、通過、安全 | 拍帶上的可踩拍 |
| `--torch` | `#E8893B` | 火把橘 | 警告、查看、太早／太晚 | 衛兵查看時的橘火把 |
| `--blood` | `#B02A1E` | 血紅 | 失敗、追殺、不可逆 | 追殺的紅火把；沿用 BloodRed |

規則：**一種顏色只代表一件事**（和 `docs/process/doc-style.md` 一致）。青銅只給「可以按」，不拿來裝飾；海青、火把橘、血紅只在狀態出現時用。文字對比至少 4.5：1。

## 3. 字型（兩種，分工清楚）

| 角色 | 字型 | 用法 |
|---|---|---|
| 題字（標題、章節、試驗場名） | Noto Serif TC 900 | 刻在石頭上的感覺；字距略開 0.04em；標題本身就是畫面主角，大到 56～72px |
| 內文與介面 | Noto Sans TC 400／500 | 說明、按鍵表、數字；數字用 `font-variant-numeric: tabular-nums` 讓面板數字不跳動 |

字級：12／14／16（內文）／20／28／44／64，行高內文 1.7、標題 1.15；內文一行不超過 36 個中文字。
不用：全大寫標籤、標題裡單一詞變色、每段上方的小眉標、等寬字型當小標。
按鍵一律用鍵帽樣式 `<kbd>`（城牆石底、青銅細框），鍵名寫在最前面。

## 4. 版面與元件

**唯一的大膽元素：拍帶**。開場標題下方一條細長的拍帶（真的照規則的拍滑動、最響一擊時整條亮一下），同一個元件也用在敲暗號試驗場、試聽頁、試玩清單的頁首。看到它就知道「這個遊戲是跟著拍走的」。尊重「減少動態效果」設定：開了就停住、只顯示靜態拍點。

```
總首頁 / 開場
┌──────────────────────────────────────────────┐
│ 木馬之夜（題字 64px，靠左）                    │
│ ▏ ·  ·  ▮  ·  ·  ▮  ·  ·  ▮  │ ← 拍帶           │
├───────────────────────────┬──────────────────┤
│ 故事三句、按鍵表（左，主）  │ 設定（右，次）     │
│                           │ [開始] 青銅按鈕     │
└───────────────────────────┴──────────────────┘

切換台：不用一格一格的卡片，改成「城區地圖」
┌ 第 1 區 城門內 ─── 第 2 區 廣場 ─── 第 3 區 窄巷 ─── 第 4 區 城門 ┐
│ 腹中練習          跑／查看／照亮      蹲走／屏息聽     （整關）   │
│                   敲暗號／追殺                                 │
└───────────────────────────────────────────────────────────┘
每個試驗場掛在它所在的區底下（試驗場本來就綁區），一句「測什麼」。

試驗場面板（遊戲中）
左上：試驗場名（題字 20px）＋三行（測／操作／看）
右上：數字（等寬數字），狀態字用海青／火把橘／血紅
下方：拍帶（有需要的試驗場才出現）
```

對齊：文字一律靠左；只有開場題字與拍帶可以滿版。面板圓角 4px（石塊感），按鈕 2px，不加陰影，用城牆石與夜空墨的明度差分層。
動態：只有拍帶會自己動；其餘只回應操作（展開、勾選、按下）。

## 5. 方向選項

| 方向 | 做法 | 好處 | 代價 |
|---|---|---|---|
| **A 夜城訊號（建議）** | 照第 2～4 節：顏色＝遊戲訊號、題字、拍帶、城區地圖切換台 | 和洞穴篇延續；介面教會玩家遊戲的顏色語言；和二次元插圖不衝突（插圖放在暗底上很跳） | 畫面角色約半天到一天 |
| B 偏二次元介面 | 介面也走動畫風：較亮、圓角、角色頭像卡、對話框式提示 | 和電繪同學的插圖風格最一致 | 和暗色寫實 3D 落差大；要等插圖出來才定得了色 |
| C 只做一致性整理 | 保留現在的顏色，只統一字級、按鍵寫法、間距 | 最快 | 沒有記憶點，簡報與海報少了識別 |

## 6. 自我檢查（避免一般預設）

- 「近黑底＋單一亮色」是常見預設 → 改成帶藍的夜空墨，而且用三個有遊戲意義的狀態色，青銅只給可按元素。
- 「一格一格的卡片牆」是常見預設 → 切換台改成照區排的地圖，因為試驗場真的綁在區上，結構本身就是資訊。
- 「題字襯線＋暖色」接近另一個常見預設 → 保留，因為它是洞穴篇已經定下的系列識別（題字標題），換掉反而斷了系列。
