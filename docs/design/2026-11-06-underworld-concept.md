# 冥府：黑暗中認出亡魂（銜接章）

內容規則：電影為主、原典補充、可適度改編（`CLAUDE.md`）。

## 核心玩法（使用者選定）：黑暗中認出亡魂【改編】

- 一片黑霧，看不見臉。亡魂一個一個靠近，你只聽得到**腳步、咳嗽、一句往事**（例如「你答應過要帶我回去看我的橄欖園」）。
- 每個亡魂靠近時，從**洞穴裡失去的同伴名單**（存檔 `crewLost`）加上幾個不相干的名字裡，選出他是誰，叫出他的名字。
- 叫對：亡魂停下來，臉在微光裡浮現一下，然後走進黑暗，安息。
- 叫錯或叫不出（時限內沒選）：亡魂哀號著從你身邊擦過，冷到發抖。他會**跟著你到海上**，成為奧吉吉亞礁石上的人影。
- 線索的來源：亡魂的往事對應各同伴在洞穴章、岸邊被砸死時的細節（死法、說過的話）。
- 沒有失去同伴的玩家（全救出來）：只有西農和阿伽門農出現，段落變短。

| 機制 | 出處 | 規則 |

| **西農的指責**（開場） | 【電影】 | 西農責備奧德修斯沒有尊敬死去的同伴，說「他們都在這裡，你叫得出他們的名字嗎？」引出核心玩法 |
| **阿伽門農的忠告**（結尾） | 【電影】 | 「別以國王的身分回家，以無名之人的身分回去。」叫對一半以上的同伴，才會聽到這句完整的忠告 → 存檔 `nameless: true` → 乞丐章開場時，所有人的疑心從較低的地方起算（偽裝更好）【改編】 |
