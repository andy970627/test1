# 底層玩法特色的發想：聲音的變化、玩家的輸入、個人風格（2026-11-14，設計席）

狀態：**發想筆記，全部未定。** 使用者 11/14 要求把這些方向（含還不確定的）先寫下來，之後再想。沒有任何一項試過，也沒有排進工作。要動工的那一項，先做試聽頁或試驗場給使用者試 5 分鐘，再寫規格。
起因：使用者想從更多角度擴展底層玩法：聲音的更多變化（速度、風格）、玩家在輸入面的參與，以及有個人風格的特色；並點名「奧德修斯標誌的弓箭射擊與弓弦聲」和「敲暗號指揮同伴」。

專有詞：**最響的一擊**＝所有鼓同時落下、特別加重的那一下，之後 0.6 秒衛兵察覺不到你；**踩得上的拍**＝夠大聲、腳步落在上面就聽不見的鼓點；**三對二**＝同一段時間裡一條鼓打三下、另一條打兩下。

每一項的格式：玩起來是什麼／和現在的玩法怎麼接／出處／最小的試法／還沒想清楚的。

## 0. 一條貫穿的想法

現在的玩法是「音樂替你蓋住聲音」，玩家只能等。下面大部分的想法都在往同一個方向推：**玩家自己也是發出聲音的人。** 落在拍上的聲音是音樂的一部分，落在拍外的聲音是破綻；而破綻有時候正是你要的（引開衛兵）。

## 1. 奧德修斯的弓：弓就是他的樂器

**為什麼是它**：荷馬寫奧德修斯給大弓上弦時，說他像樂師給里拉琴上弦，試彈一下，弦聲像燕子叫【原典第 21 卷】。弓在原典裡本來就被當成樂器來寫。這個遊戲又是用聲音當規則，兩件事可以合在一起，變成只有這個遊戲有的東西。

### 1.1 拉弓是一條你自己控制的上升音

- **玩起來**：按住拉弓，弦越拉越緊，一個音跟著往上升。放開就射。拉到滿之後繼續撐著，弓身開始吱嘎作響，那是會被聽到的聲音。
- **和現在怎麼接**：放箭的那一下要落在最響的一擊上，弦聲才會被蓋住。拉弓的上升音正好是「越打越密」的另一個版本，只是這次是玩家自己做出來的；兩個上升的聲音一起衝到同一個點放開。
- **出處**：弦聲如燕鳴【原典】；拉弓音隨張力上升【改編】。
- **最小的試法**：聲音試聽頁加一顆「拉弓」鍵，只做上升音、放開的弦聲、和最響一擊的對準程度顯示。
- **沒想清楚的**：比箭原型已經有一套（心跳加速、準心晃動），要合併還是並存。

### 1.2 箭要飛一段時間，所以要提前放

- **玩起來**：箭射到目標需要時間，遠的要早一點放。你要讓「箭射中的聲音」落在最響的一擊上，不是「放箭的聲音」。距離越遠，越要提前。
- **和現在怎麼接**：現在所有動作都是「那一擊落下時按」。這是第一個要算提前量的動作，而且提前量由距離決定，看得到、學得會。
- **出處**【改編】。
- **最小的試法**：比箭原型裡加一個固定距離的靶，畫面顯示箭的飛行時間與落點離那一擊差多少。
- **沒想清楚的**：放箭的弦聲本身沒被蓋住怎麼辦。可能的答案：弦聲小、只傳得近；真正大聲的是射中。

### 1.3 空彈弓弦：不搭箭，只彈一下

- **玩起來**：不搭箭彈一下弦，發出一個清楚的音。落在拍上，它聽起來是音樂的一部分，沒有人理；落在拍外，附近的衛兵會過來查看。
- **和現在怎麼接**：這就是先前想過的「丟石子引開」，但不用撿東西、不用加道具，而且是主角專屬的聲音。也可以當成敲暗號的工具（第 3 節）。
- **出處**：試弦一彈【原典】；用來引開衛兵【改編】。
- **最小的試法**：查看的試驗場（`?lab=check`）裡加一顆鍵，彈一下弦，看衛兵會不會過來。
- **沒想清楚的**：方向。弦聲是從你身上發出的，衛兵會朝你來，和丟石子把人引到別處不一樣。可能要搭配「彈完立刻踩著鼓點離開」。

### 1.4 射東西，不射人

- **玩起來**：射熄火盆，那一帶變成影子；射中掛著的盾或銅鍋，發出一聲很響的金屬聲，把遠處的衛兵引過去，或是替同伴製造一次掩護。
- **和現在怎麼接**：自己造影子、自己造一擊。回應「大部分時間在等」。
- **出處**【改編】。
- **沒想清楚的**：箭有幾支、能不能撿回來；會不會讓潛行變成射擊遊戲。

### 1.5 一個要先講的限制

原典裡那把大弓留在伊薩卡的家裡，奧德修斯沒有帶去特洛伊【原典第 21 卷】。所以木馬之夜裡如果有弓，是一把普通的弓【改編】，「那把弓」的份量要留給比箭與大廳復仇兩章。比較穩的做法：1.1、1.2 先放在比箭與大廳復仇；1.3、1.4 如果要進木馬之夜，就明說是另一把弓，或換成別的道具。

## 2. 離鼓越近越能動

- **玩起來**：鼓聲有來源。廣場上有一群慶祝的鼓手，離他們越近，鼓聲越大，蓋得住的動作越大（跑、撲倒、打翻東西）；離遠了，例如窄巷裡，鼓聲薄，只蓋得住輕手輕腳。
- **和現在怎麼接**：現在掩護在整關都一樣強，所以玩家永遠繞得開衛兵（關卡重排要解的問題）。掩護有了強弱，路線就有了取捨：繞遠路走鼓聲大的地方，或抄近路但得很小心。木馬共鳴已經是「離木馬越近那一擊越厚」，這是把同一件事變成規則。
- **出處**：特洛伊人慶祝木馬進城【經典】；鼓手的位置與掩護強弱【改編】。
- **最小的試法**：試驗場一個鼓手、一名衛兵、兩條路。只改「掩護窗的長度隨離鼓的距離變」一個數字。
- **沒想清楚的**：喇叭上聽不出遠近怎麼辦（靠音量與畫面上鼓手的火光）；鼓手自己會不會看到你。

## 3. 玩家自己補一拍，與敲暗號指揮同伴

### 3.1 自己補一拍

- **玩起來**：你發出的聲音只要落在踩得上的拍上，衛兵就當成祭典的一部分。敲一下木馬的腹板、敲一下盾，等於在那個拍子上加了一下重音。連續幾下都敲在拍上，那幾拍之間你可以做一個中等大小的動作。
- **和現在怎麼接**：現在大動作只能等最響的一擊。這讓玩家可以用技巧「買」到一小段掩護，比最響一擊短、比它弱，但時機自己決定。敲歪了就是一聲破綻。
- **出處**【改編】。
- **最小的試法**：聲音試聽頁加一顆「敲」鍵，顯示每一下離拍子差多少、連續幾下在拍上；先不接規則。
- **沒想清楚的**：會不會變成一直敲就一直安全。要有代價：敲的時候不能走，或每敲一次疑心都漲一點、只有敲準才抵銷。

### 3.2 敲暗號指揮同伴

- **玩起來**：同伴還躲在木馬裡。你用敲擊對他們下指令：一組三下是「引開」，木馬那邊傳出一聲響，附近的衛兵回頭；一組兩下是「現在」，同伴在下一次最響的一擊時動手（開城門前解決木馬旁的衛兵，或是從裡面打開暗門）。暗號要敲在拍上，同伴才聽得懂、衛兵才不起疑。
- **和現在怎麼接**：木馬腹中的練習裡，同伴已經會「趁最響的一擊開暗門」；結尾也有同伴落地放倒衛兵。這是把那兩個只能看的演出，變成玩家下令的事。三下與兩下，正好是第二步在做的三對二。
- **出處**：同伴藏在木馬裡【經典】；原典第 4 卷有木馬裡的人被外面的聲音考驗、奧德修斯按住同伴不讓他出聲的段落【原典】，可以反過來用成「只有對的暗號他們才動」；敲擊暗號【改編】。
- **最小的試法**：木馬試驗場（`?lab=horse`）裡加兩種暗號，同伴只回應一個動作（木馬傳出一聲響），看玩家學不學得會、敲不敲得準。
- **沒想清楚的**：離木馬多遠還下得了令；暗號有幾種才不會記不住（先兩種）；敲錯暗號的後果。

### 3.3 調息

- **玩起來**：屏息改成跟著最慢的那條鼓一吸一吐。跟得上，氣就一直夠；跟不上才會憋到喘出聲。
- **和現在怎麼接**：安撫已經拿掉了，「跟著最慢的聲音」這個玩法沒有地方放。調息是它有故事的版本，而且不用新的鍵。
- **出處**【改編】。
- **沒想清楚的**：屏息現在是「按住」，改成有節奏的按放會不會太忙；和「屏息時聽衛兵腳步」同時進行會不會打架。

## 4. 最響的一擊照亮場景

- **玩起來**：平常畫面比現在更暗，只看得到火光附近。每一次最響的一擊落下，一圈震波從鼓聲的方向掃過整個場景，半秒之內把所有衛兵的輪廓照出來，連牆後面的也看得到，然後暗回去。
- **和現在怎麼接**：那一擊現在只是掩護。加上這個，它同時是你唯一看得清楚全局的時刻：你要在同一瞬間決定是趁掩護動手，還是用這半秒看路。現在已經有那一擊的白閃與落塵，是把它從裝飾變成資訊。
- **為什麼算個人風格**：上一個作品《雙盲洞穴》就是「聲波照亮黑暗」。這是同一個招牌在新遊戲裡的樣子：上次是你發出聲音去看，這次是世界的聲音讓你看。
- **出處**【改編】。
- **最小的試法**：只動畫面。試驗場裡把環境調暗，那一擊落下時顯示衛兵輪廓半秒。看使用者會不會開始「等那一擊來看路」。
- **沒想清楚的**：太暗會不會讓第一次玩的人不知道往哪走（前兩區可以亮一點）；衛兵在那半秒是不是也看得到你（建議看不到，那一擊本來就是他們察覺不到的時候）。

## 5. 聲音的風格與速度

### 5.1 每一區一種材質

- **玩起來**：木馬裡是悶的木箱聲；廣場是祭典的框鼓；窄巷是陶罐與水聲；城門是鐵與盾。什麼材質蓋得住什麼聲音：鐵的聲音蓋得住推門閂，木的聲音蓋得住踩木板。
- **和現在怎麼接**：讓「蓋住」有種類，不只有大小。推門閂現在是「節奏快就放開」，可以改成「等鐵聲」。
- **沒想清楚的**：種類一多，第一次玩的人記不記得住。先只做一組（鐵對門閂）。

### 5.2 減速的錯覺

- **玩起來**：同一招反過來，聽起來永遠在變慢、永遠慢不下來。
- **用在哪**：躲藏時（和追殺的真加速相對）、冥府那一章、或被追殺後甩掉的那一段。
- **沒想清楚的**：加速都還沒在遊戲裡成立，這一項排在它之後。

### 5.3 兩拍的衛兵與三拍的衛兵

- **玩起來**：不同的衛兵踩不同的拍型。聽腳步是兩下一組還是三下一組，就知道是哪一種衛兵（例如巡邏的與站崗的、普通的與精銳的），應付的方法不同。
- **和現在怎麼接**：屏息時已經聽得到衛兵的腳步；第二步的三對二提供了兩種拍型。
- **沒想清楚的**：兩種衛兵的差別要大到值得分辨。

### 5.4 整關真的越來越快

使用者 11/11 已經選了「兩種都要」（一圈之內聽得出變快，整關也真的越來越快）。記在這裡避免漏掉：越靠近城門，一圈越短、差距拉大；久站也會慢慢變快。等加速錯覺第三步有結論再做。

## 8. 留給使用者之後想的問題

1. 弓要不要進木馬之夜（那不是「那把弓」），還是留到比箭與大廳復仇才出現？
2. 「玩家自己發出聲音」要做到多深：只是多一個引開的工具，還是變成和「等最響的一擊」並列的主玩法？
3. 敲暗號的對象只有木馬裡的同伴，還是之後的章節也有（兒子、牧豬人）？
4. 畫面要暗到什麼程度：只是氣氛，還是真的要靠那一擊才看得到路？
5. 系列骨架那張表，是當成之後各章的規劃，還是只當成介紹用的一句話？

## 9. 原型期間的裁決

- **11/15　空彈弓弦落在掩護窗裡算不算被蓋住：算。** 最響的一擊加上它之後的 0.6 秒，衛兵什麼都察覺不到，這條規則對跑步、衝刺、暗殺都成立，彈弦不該例外。所以彈弦有兩種被蓋住的情況：落在踩得上的拍上（±判定寬度），或落在掩護窗裡（整段）。反過來說，想用彈弦引開衛兵，就不能挑那一擊剛落下的時候彈。原型量到的「拍上 0 次查看、拍外全部有人來」方向正確，照這條補上掩護窗即可。
