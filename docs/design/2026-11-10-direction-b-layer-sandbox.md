# 方向乙「換層」試驗場規格（2026-11-10）

狀態：**設計席（Fable）規格，供 agy 寫第一版、規則角色收尾**。報告後才做進正式原型；這份只做一個可單獨開的試驗場，用來回答「換層這個玩法成不成立」。
依據：`2026-11-10-core-direction-illusion.md` 第 1 節方向乙；`CLAUDE.md`「設計與測試」；`2026-11-08-music-core-concept.md` 第 5 節 13 條規則；拍點公式沿用 `prototypes/troy-prologue/risset.js`。
範圍：新資料夾 `prototypes/layer-ride/`，**不碰** `prototypes/troy-prologue/` 與其他原型的任何檔案，也不改 `prototypes/index.html`、`tools/`。
出處：木馬之夜、希臘人趁夜潛行【經典】；城裡慶祝的鼓聲蓋住腳步、腳步騎在一層鼓上【改編】；Risset 節奏【原理：Risset】。不得出現現代元素（試驗場的數字面板除外）。

專有詞：**聲部**＝一條持續加速的鼓，從很慢、很小聲進場，越來越快，最後太快而淡出；同時聽得到四條。**騎**＝玩家的腳步落在某一條聲部的拍上。**換層**＝改騎比現在慢一倍、剛進場的那一條。**u**＝一條聲部進場後過了幾個循環（0 剛進場，4 淡出）。**遮蓋**＝大聲蓋過小聲。

---

## 1. 玩法一句話

按住前進，腳步自動落在你「騎」的那條聲部的拍上、被鼓聲蓋住；這條聲部會越來越快，快到腳跟不上之前，要在對的那一拍按「換層」，改騎底下悄悄進場的慢聲部。**太早換**，新聲部還太小聲，蓋不住腳步；**太晚換**，腳跟不上，踩亂出聲；**按歪了**，腳下一亂響一聲。出聲會讓衛兵起疑，疑心滿了才算被發現。鼓聲從頭到尾不中斷。

場景：城牆下一條 18 公尺的直巷，一名衛兵站在中間不動，只用耳朵。從西端走到東端就過關。

## 2. 數學（照做，不要自己換公式）

時間一律用音訊時鐘絕對秒數 `t`（`AudioContext.currentTime`）。`t0`＝開局時間。

- 聲部編號 `j`（整數，可為負）。聲部 j 的年齡：`u_j(t) = (t − t0) ÷ CYCLE − j`。`0 ≤ u < LAYERS` 時才存在（聽得到）。每過一個 `CYCLE`，有一條新聲部在 u = 0 進場，最老的一條在 u = `LAYERS` 消失。任何時刻剛好 `LAYERS` 條。
- 聲部的第 c 拍（c = 0, 1, 2 …）在 `u = log2(1 + c ÷ M)`，也就是 `t = t0 + (j + log2(1 + c ÷ M)) × CYCLE`。
- 音量（鐘形）：`gain(u) = exp(−((u ÷ LAYERS − 0.5)²) ÷ (2 × SIGMA²))`。
- 拍距 `interval(u)`：包住 u 的那兩拍的時間差。`c = floor(M × (2^u − 1))`，`interval = (log2(1 + (c+1) ÷ M) − log2(1 + c ÷ M)) × CYCLE`。
- **重合**：聲部 j+1（慢一倍那條）的第 c′ 拍，和聲部 j 的第 `2c′ + M` 拍在同一瞬間。換層只在這種重合拍上才乾淨。
- 一條聲部「騎得住」的條件：`gain(u) ≥ COVER_GAIN`（夠響，蓋得住腳步）**且** `interval(u) ≥ STRIDE_MIN`（不會快到跟不上）。
- **換層窗**：現在騎的聲部還騎得住，而且底下那條（u − 1）也已經騎得住的那段時間。

預設常數下算出來的數字（測試要驗，容許誤差見第 7 節）：

| 項目 | 值 |
|---|---|
| 一條聲部騎得住的範圍 | u = 0.286 ～ 1.585（拍距 1.52 → 0.61 秒，音量 0.15 → 0.90） |
| 換層窗（以現在騎的聲部的 u 計） | 1.286 ～ 1.585，寬 0.30 個循環＝約 3.0 秒 |
| 窗內的重合拍 | 底下那條的第 2、3 拍（u = 1.322、1.459），這時它的音量只有 0.16、0.22 |
| 同一時間其他聲部的音量 | 現在騎的 0.72～0.90、再快一條約 0.9～1.0 |

也就是說：玩家要在一片響亮的鼓聲底下，聽出一條只有 0.16～0.22 的慢鼓已經進來了。這就是「新聲部在遮蓋下悄悄進場」，也是這個試驗場要驗的事。

## 3. 常數表（全部放 `rules.js` 的 `T`，`Object.freeze`；每個旁邊加中文註解）

| 常數 | 預設 | 說明 |
|---|---|---|
| `CYCLE` | 10 | 一個循環秒數（固定，不做越危險越快） |
| `M` | 8 | 最慢那一層每循環的拍數 |
| `LAYERS` | 4 | 同時存在的聲部數 |
| `SIGMA` | 0.22 | 鐘形音量的寬度 |
| `COVER_GAIN` | 0.15 | 騎的聲部音量至少多少才蓋得住腳步 |
| `STRIDE_MIN` | 0.6 | 腳步最快多久一步（秒）；拍距比這短就跟不上 |
| `SWITCH_WIN` | 0.15 | 換層鍵離重合拍多近算準（± 秒） |
| `STEP_LEN` | 0.6 | 一步走多遠（公尺） |
| `LANE` | 18 | 巷子長度（公尺）；玩家從 x = 0 走到 x = `LANE` |
| `GUARD_X` | 9 | 衛兵位置 |
| `SUSP_LOUD` | 0.4 | 衛兵聽到一次出聲增加的疑心（11/10 第 10 節：原 0.3 作廢，用實作現值） |
| `SUSP_DECAY` | 0.02 | 每秒退的疑心（11/10 第 10 節：原 0.03 作廢，用實作現值） |
| `RIDE_START_U` | 0.6 | 開局騎的那條聲部的 u（開局不在換層窗裡，先有時間聽） |
| `RIDE_BOOST_DB` | 2 | 現在騎的聲部在聲音層多響幾 dB（教學輔助，可調到 0） |
| `ENTER_KNOCK_GAIN` | 0.5 | 剛進場的聲部（u < 1.3）加的中頻敲擊音量係數（喇叭也聽得到，見第 5 節） |
| `MAX_DT` | 0.1 | `step` 一次最多推進幾秒（移動用；拍點照實際時間算） |

不變的條件（測試要驗）：`COVER_GAIN`、`STRIDE_MIN` 的組合必須讓換層窗寬 ≥ 0.2 個循環，而且每個循環窗內至少有 1 個重合拍。`createGame` 收到讓這條不成立的常數時丟錯，訊息用中文。

## 4. 規則模組 `rules.js`

純邏輯，不碰 DOM 與 Web Audio；UMD（瀏覽器全域 `LayerRideRules`，Node `module.exports`）；之後要能翻成 C#。寫法照 `prototypes/troy-prologue/risset.js` 的習慣：檔頭中文註解寫規則、常數表、事件；提示文字裡的數字由常數生成。

### 4.1 匯出
- `T`、`createGame(opts)`、`step(game, t, input)`、`drain(game)`（取走並清空事件）。
- 純函式：`voiceU(j, t, game)`、`gainAt(u, K)`、`beatU(c, K)`、`beatTime(j, c, game)`、`intervalAt(u, K)`、`rideable(u, K)`、`voicesAt(t, game)`（回 `[{id, u, gain, interval, rideable, nextBeat}]`，慢到快排）、`beatsBetween(a, b, game)`（回 `[{t, id, c, gain}]`，聲音層排程用）、`switchWindows(a, b, game)`（回 `[{from, to, beats:[t…]}]`，以目前騎的聲部為準）、`coincidentBeats(a, b, game)`（底下那條在 a～b 的拍，就是可以乾淨換層的時刻）。
- 程式玩家：`botInput(game, t, bot)`，`bot = {kind, sigma, react}`，種類見第 7 節。
- `EVENTS`：所有事件名的陣列（測試拿來對聲音與畫面有沒有接）。
- `HINTS`、`hintsFor(K)`：第 4.5 節的文字。

### 4.2 `createGame({t0, seed, T})`
回傳 `game`：`{T, t0, time, phase:'play'|'win'|'fail', player:{x:0, walking:false}, ride:{id, since}, guard:{x, susp:0}, window:{open:false, from:null, to:null}, stats:{steps:0, loud:0, switches:0, switchOff:0}, out:[]}`。
開局騎的聲部：`u` 最接近 `RIDE_START_U` 的那一條。亂數只用 `seed`（照抄 `risset.js` 的 `mulberry32`）；這份規格目前沒有隨機事件，`seed` 只影響 `t0` 的相位偏移（`t0 += rng() × CYCLE`，讓各局起點不同）。

### 4.3 `input`
`{walk: boolean（按住前進）, switchAt: number|null（這一幀按了換層鍵；值＝按鍵當下的音訊時間，已扣輸出延遲；沒按為 null）}`。

### 4.4 `step(game, t, input)` 每幀
1. 更新 `game.time`、`voicesAt`、`game.window`（開關變化時發 `window_open {from, to}`／`window_close`）。新聲部進場那一幀發 `voice_in {id}`。
2. **換層**（`switchAt` 不為 null）：目標＝`ride.id + 1`（慢一倍那條）。
   - 目標的 u < 0（還沒進場）→ 發 `switch_none`，什麼都不變，不加疑心。
   - 否則一定換過去（`ride.id += 1`、`stats.switches += 1`）。算 `off = switchAt − 最近的重合拍時間`（用 `coincidentBeats`）。`|off| ≤ SWITCH_WIN` → `switch_ok {from, to, off}`；否則 → `switch_off {from, to, off}`，算一次出聲（見第 4 點），`stats.switchOff += 1`。
   - 換層本身不看目標騎不騎得住。太早換的代價由第 3 點自然發生。
3. **腳步**（`walk` 為真才有）：
   - 現在騎的聲部拍距 ≥ `STRIDE_MIN`：這一幀跨過它的每一拍各走一步，`player.x += STEP_LEN`。音量 ≥ `COVER_GAIN` → `step_masked {id, t, x}`；不夠 → `step_loud {cause:'thin', id, t, x}`（鼓太輕，蓋不住）。
   - 拍距 < `STRIDE_MIN`（跟不上）：改成每 `STRIDE_MIN` 秒走一步，不對拍 → `step_loud {cause:'fast', id, t, x}`。
   - 騎的聲部已經消失（u ≥ `LAYERS`）：同「跟不上」處理，直到玩家換層。
   - 從站著開始走：第一步落在騎的聲部的下一拍，不另外判起步。
4. **出聲**（`step_loud` 或 `switch_off`）：`guard.susp += SUSP_LOUD`，同時發 `guard_hear {susp}`。沒出聲時每秒退 `SUSP_DECAY`，不低於 0。`susp ≥ 1` → `phase = 'fail'`，發 `caught`。
5. `player.x ≥ LANE` → `phase = 'win'`，發 `win {time, loud, switches}`。
6. 站著不動沒有任何懲罰，但聲部照樣變老；站太久要連按幾次換層才騎得回去。

### 4.5 提示文字（`hintsFor(K)`，數字由常數生成）
- `intro`：`'按住 W 往前走，腳步會落在鼓點上、被鼓聲蓋住。你踩的那條鼓會越來越快。'`
- `switch`：`'聽：底下有一條慢一倍的鼓悄悄進來了。等它夠響，在兩條鼓同時落下的那一拍按 Q，改踩慢的那條。'`
- `thin`：`'換得太早：那條鼓還太輕，蓋不住你的腳步。'`
- `fast`：`'鼓太快，腳跟不上了：快按 Q 換到慢的那條。'`
- `off`：`'沒按在兩條鼓同時落下的那一拍上，腳下亂了一聲。'`
- `caught`：`'衛兵聽見了。'`

## 5. 聲音 `audio.js`（每個判定輸入都要有聲音）

UMD，全域 `LayerRideAudio`，`createAudio(ctx, {rules})`；純 Web Audio 合成，不用音檔。**拍點與常數全部讀規則**（`beatsBetween`、`gainAt`、`T`），自己不算相位。排程照 `troy-prologue/audio.js` 的做法：計時器每 25 ms 把接下來 0.3 秒的拍用 `ctx.currentTime` 絕對時間預排。

| 事件／輸入 | 聲音 | 頻段 |
|---|---|---|
| 每條聲部的每一拍 | 一記打擊，音色依 `u ÷ LAYERS` 從低鼓 → 框鼓 → 手拍 → 金屬平滑過渡；音量＝`gainAt(u)`；現在騎的那條再加 `RIDE_BOOST_DB` | 低鼓 90 Hz、框鼓 250 Hz、手拍 900 Hz、金屬 3 kHz 附近 |
| 剛進場的聲部（u < 1.3）的每一拍 | 另外疊一聲短促的木頭敲擊，音量＝`gainAt(u) × ENTER_KNOCK_GAIN`。理由：低鼓在筆電喇叭上聽不到，進場的聲部一定要有 200～4000 Hz 的成分（總綱規則 6） | 400～800 Hz |
| `step_masked` | 很輕的布料腳步 | 500～900 Hz，音量 0.08 |
| `step_loud`（`thin`、`fast`） | 碎石「喀嚓」 | 1.5～3.5 kHz，音量 0.5 |
| `switch_ok` | 里拉琴（古希臘的弦樂器）撥一個音 | 500～900 Hz |
| `switch_off` | 腳下一亂的摩擦聲 | 1～3 kHz |
| `switch_none` | 很輕的悶聲 | 300 Hz，音量 0.1 |
| `guard_hear` | 衛兵「嗯？」短促一聲，疑心越高越長 | 200～600 Hz |
| `window_open`／`window_close` | **不發聲**（它是要玩家自己聽出來的事；畫面輔助可顯示） | — |
| `caught`、`win` | 短號角下行／上行 | 300～1200 Hz |

對外：`update(game)`（每幀）、`cue(event)`、`CUES`（事件名 → 函式的表，測試用）、`setMaster(v)`、`dispose()`。不得有任何把鼓聲整體壓低或靜音的排程。

## 6. 畫面 `index.html`（每個判定輸入都要有畫面）

HTML 片段（開頭 `<title>`，不要 doctype，同其他原型）；2D `<canvas>` 即可，不用 three.js。載入順序：`rules.js` → `audio.js` → 頁內主程式。主迴圈：`t = audio.now()` → `Rules.step(game, t, input)` → 畫 → `audio.update(game)` → `Rules.drain(game)` 分派。按鍵：W／↑ 前進，Q 換層（`switchAt = ctx.currentTime − ctx.outputLatency`），R 重來。

1. **巷子（上半）**：側視。玩家、站著的衛兵、火把；腳印 `step_masked` 藍色、`step_loud` 橘色；`guard_hear` 時衛兵頭轉向玩家；衛兵頭上的火把顏色隨疑心由黃轉紅。
2. **聲部譜（下半，試驗場的判定數字）**：四列，慢的在下、快的在上，每列畫未來 3 秒的拍（往左流動，中央一條「現在」線）；列的亮度＝音量；現在騎的那列加外框；騎不住的時段把列底色變暗（太輕）或加斜線（太快）；換層窗在騎的那列與下一列之間畫一條連接帶，重合拍畫成跨兩列的豎線。
3. **數字面板**：騎的聲部 `u`、音量、拍距；下一條的 `u`、音量；換層窗（開／關、還剩幾秒）；上一次換層的偏差（毫秒，正＝晚按）；疑心；步數、出聲次數、換層次數。
4. **常數即時調**：滑桿 `CYCLE`、`STRIDE_MIN`、`COVER_GAIN`、`SWITCH_WIN`、`RIDE_BOOST_DB`、`ENTER_KNOCK_GAIN`；改了按「重來」生效。網址參數同名可覆寫（例如 `?CYCLE=12`）。
5. **輔助開關**：「聲部譜」可關（`?aid=0`）。關掉後只剩巷子與聲音，用來測「只靠耳朵行不行」。
6. 提示文字用 `Rules.hintsFor`：開局顯示 `intro`；第一次換層窗開時顯示 `switch`；`step_loud`、`switch_off` 各自第一次發生時顯示對應文字。
7. 結束畫面：過關或被發現，列出時間、出聲次數、換層次數與每次偏差。
8. 除錯物件 `window.LayerRideDebug = {game, audio, ctx}`。

## 10. A10 過不了的裁決（設計席，11/10 夜）

規則角色回報：手不準的程式玩家（按鍵誤差 σ 0.25 秒）在預設巷長下 20 局全過，把 `SUSP_LOUD`、`SUSP_DECAY` 在准許範圍內調到底也一樣；18 公尺只換 3 次層，三次全按歪疑心最高也只到 0.8。

**裁決：A10 原本的寫法作廢，是我訂錯了，不是實作的問題。**
- 原因：規格自己規定「按歪只響一聲、疑心加一次」，一局又只換 3 次，所以按得再歪也不可能失敗。我卻拿「過關率要差 20 個百分點」當驗收，兩件事互相矛盾。這和木馬之夜 7.1 犯的是同一個錯：代價設計成不致命，卻用過關率量它。
- 不改規則：按歪不加重。這個試驗場要回答的是「聽不聽得出底下那條慢鼓進來了」，也就是**什麼時候換**（太早、太晚），A8、A9、A11 已經量到而且都過。按得準不準是次要的。
- `SUSP_LOUD` 0.4、`SUSP_DECAY` 0.02 就用現值（第 3 節常數表的預設值跟著改成這兩個數，原本寫的 0.3／0.03 作廢）。

**A10 改成兩條**（規則角色改測試；第一條要過，第二條只印不擋）：

| # | 檢查 | 門檻 |
|---|---|---|
| A10a | 手不準要付得出代價：預設巷長下，每局平均按歪次數（`stats.switchOff`） | σ 0.08 ≤ 0.5 次；σ 0.25 ≥ 1.2 次（理論值約 0.18 與 1.65：按鍵落在 ±0.15 秒外的機率分別是 6% 與 55%，乘 3 次換層） |
| A10b | 路一長，手不準就走不完：`LANE` 改 60 公尺（約換 10 次層），其他常數不變 | 只印 σ 0.08 與 σ 0.25 的過關率與平均最高疑心，不設門檻。用途是告訴之後的正式版：一局要換幾次層，手的準度才開始有分別 |

A10b 不設門檻的理由：正式版一局多長、換層之外還疊什麼動作都還沒設計，現在訂數字又會是猜的。

**順帶記一筆給試玩**：預設 18 公尺、約 30 秒、換 3 次，是為了讓使用者快速重來、專心聽。若使用者第一次就過，把「聲部譜」關掉再玩一次才是這個試驗場真正的題目（第 9 節第 1 題）。
