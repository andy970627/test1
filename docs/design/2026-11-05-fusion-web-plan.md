# 融合版網頁原型計畫（11/12 專案報告用）

日期：2026-11-05　報告：2026-11-12（四）　上架：itch.io（HTML5）　展示：電腦（鍵盤滑鼠）
依據：`2026-11-05-fusion-analysis.md`；內容規則見 `CLAUDE.md`（電影為主、原典補充、可適度改編，標出處）。

## 1. 使用者的決定（11/05）

- 做**融合版**，原型程度即可。
- **洞穴章**：使用者試著設定 Unity 雲端建置（`ci-webgl-itch` 分支的 `docs/ci-setup.md`）。成功就放主線網頁版；來不及就在系列首頁放影片。不重做主線。
- **奧吉吉亞章**：只做過場。
- **跨章影響**：四項全做（見第 3 節）。

## 2. 流程

```
系列首頁（標題、章節地圖、繼續／重新開始）
 → 第一章 洞穴【電影】：主線 Unity 網頁版，或影片
 → 銀接 岸邊的抉擇【電影】：射箭／喊出名字／默默離開（主線規格第 20 節 C 的網頁版）
 → 第二章 奧吉吉亞（過場）【電影＋改編】：困在島上 N 年；沒救出的同伴站在礁石上；造筏出海；漂到伊薩卡
 → 第三章 門檻上的乞丐（宮門→大廳）
 → 第四章 伊薩卡比箭
 → 終章【電影】：父子殺掉求婚者；奧德修斯把王位交給忒勒馬科斯，和潘妮洛普往西航行
```

每章結束回到系列流程的下一步；各章也能從首頁單獨開始（用預設存檔）。

## 3. 跨章存檔（所有章共用）

`localStorage` 鍵 `odyssey-series-v1`，JSON：

| 欄位 | 型別 | 誰寫 | 誰讀 |
|---|---|---|---|
| `step` | `'cave'\|'shore'\|'ogygia'\|'beggar-gate'\|'beggar-hall'\|'bow'\|'ending'` | 每章結束時 | 首頁「繼續」 |
| `crewOut` | 帶出洞的同伴數，預設 6 | 洞穴（若有 Unity 版）或岸邊預設 | 岸邊 |
| `crewLost` | 失去的同伴名單（字串陣列） | 岸邊 | 奧吉吉亞過場 |
| `shore` | `'shoot'\|'name'\|'leave'` | 岸邊 | 規則 |
| `wrath` | 0～2 | 規則（由 `shore` 算） | 規則 |
| `years` | 7～9 | 規則（由 `wrath` 算） | 乞丐、終章 |
| `ledger` | 乞丐記的帳（整數） | 乞丐 | 比箭 |
| `knowers` | `{tele, eum, pen}`，同乞丐的 `carry` | 乞丐 | 比箭、終章 |
| `bow` | `{win, passed}` | 比箭 | 終章 |

**換算規則**（寫在純邏輯模組 `prototypes/odyssey-series/series.js`，有測試；之後翻 C#）：
- `wrath`：默默離開 0、喊出名字 1【原典：波塞頓記住了名字】、射箭 2【電影：取代喊名的致命錯誤，招來追殺】。
- `years = 7 + wrath`（7 年【原典】）。
- 乞丐難度：`years` 每多 1 年，求婚者回頭看的機率 ×1.12、會丟東西的人多 1 個（由嘲弄者改）。【改編】
- 比箭穩定度：晃動倍率 `max(0.6, 1 − 0.04 × ledger)`。【改編】
- 岸邊損失：射箭或喊名時，每名帶出的同伴各有 1/3 機率被岩石砸死（主線規格第 20 節 C）。
- 奧吉吉亞過場：`crewLost` 每人一個站在礁石上的人影並唸出名字；年數一年一年刻在沙灘上。【改編】

## 4. 檔案與網址（itch.io 同一個網域，存檔共用）

```
dist/odyssey-series/
  index.html          系列首頁
  shore/index.html    岸邊的抉擇
  ogygia/index.html   奧吉吉亞過場
  ending/index.html   終章
  beggar/index.html + sim.js     （?series=1 時讀寫存檔）
  bow/index.html + rules.js      （?series=1 時讀寫存檔）
  cave/               主線 Unity WebGL（有的話）
  lib/three.min.js    本地一份，展示當天不怕網路不穩
  series.js
```

原始檔：`prototypes/odyssey-series/`（首頁、銀接、過場、終章、`series.js`）、`prototypes/beggar-hall/`、`prototypes/bow-contest/`。
打包腳本：`tools/build-itch.sh` 把原始檔（片段）包成完整 HTML、改用本地 three.js、輸出 zip。
