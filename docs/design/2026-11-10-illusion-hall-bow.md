# 大廳復仇與比箭改成「維持無限加速錯覺」（2026-11-10，設計席定稿）

狀態：**設計定稿，報告後才實作；不改程式。** 取代 agy 初稿 `2026-11-10-illusion-hall-bow-draft.md`（初稿留作紀錄，內容以本檔為準）。
依據：`2026-11-10-core-direction-illusion.md`（木馬之夜方向甲與第 7 節裁決）、`2026-11-10-direction-b-layer-sandbox.md`（方向乙試驗場）、`2026-11-08-vengeance-v2-spec.md`（大廳復仇合成版，以下稱 v2）、`2026-11-07-risset-bow-vengeance.md` 第 2 節、`prototypes/bow-risset/rules.js` 檔頭與常數表 `TUNING`、`2026-11-08-music-core-concept.md` 第 5 節。
專有詞：**空檔／驟降**＝現版鼓聲（比箭是心跳）斷掉的 0.6／0.5 秒；**掩護窗**＝同一段時間，但聲音不斷，改成各層同時落下的重擊加餘韻；**重合擊**＝交接時各層第一拍疊在一起的那一擊；**揮砍拍**＝v2 裡盟友敲盾沿的那條固定拍線，踩上去放箭或出矛才算數；**破綻傷害**＝頭目露出空隙時才打得進去的傷害。

初稿沒採用的部分與理由：比箭的「踩拍箭」與三個新常數（`BOW_SPREAD_TAP`、`BOW_COINCIDENT_BOOST_DB`、`BOW_LEAD_GRACE`）沒有依據，而且替一個只有一個決定的原型多加一種輸入；「實測可保證 +14 dB」沒有實測；議題 2 的建議會打破 v2 已審定的每循環傷害上限；驗收數字 85%、88%、0.5 dB 沒有來源。下面的新常數一律標【新】，數值一律標【假設，待量】。

## 0. 結論

1. **兩個原型都照木馬之夜甲版的同一招改：時間窗不搬，從「靜」改成「響」。** 各自一個開關，舊做法留著對照。
2. **大廳復仇改起來最順**：v2 本來就有「踩在拍上放箭，弓弦聲被鼓吞掉」。空檔箭改成掩護窗之後，它就是「最大的那一下踩拍箭」，同一條道理從小講到大，不用多教一件事。
3. **比箭只改聲音的接縫，不加新輸入。** 它的核心是「撐到最穩的那一瞬放箭」，等待本來就是射箭的一部分；要修的只是那一瞬不該靠心跳停掉來表示。
4. **有一個初稿漏掉、非改不可的地方**：比箭的心跳現在在循環尾端額外拉高音量，靠驟降的靜默藏住重來時的落差。靜默拿掉後落差會露出來，必須一起拿掉（第 2.2 節）。
5. 方向乙「換層」不放進比箭；大廳復仇只在最後一名頭目那一段留一個接口，等試驗場有結果再決定（第 3 節）。

## 1. 大廳復仇（以 v2 規格為底）

### 1.1 改什麼、留什麼

| v2 的項目（節號） | 現在 | 改成 | 理由 |
|---|---|---|---|
| 空檔（4.1、5） | 每循環開頭 `GAP_LEN` 0.6 秒：鼓斷、盾沿停、全場凍結泛藍 | **掩護窗**：鼓與盾沿都不停；交接那一下各層同時落下，兩位盟友同時重擊盾面一下（重合擊），接 0.6 秒餘韻；畫面不凍結、不泛藍，改成重擊的震波（爐火一竄、桌上杯盤一跳） | 和木馬之夜同一個理由 |
| 空檔箭（6.1） | 偏差 0、不暴露、一輪一次 | 判定完全不變，改名**掩護箭**；說法從「鼓一斷放箭」改成「趁最響的一擊放箭，弓弦聲整個被吞掉」 | 和踩拍箭同一個道理，只是更大 |
| 空檔推擊（7.4） | 必中、一輪一次 | 判定完全不變；說法改成「借那一擊的勢把人推開」 | — |
| 預告的空心木塊兩聲（4.4） | 每次空檔前都有 | 降為教學輔助，見 1.3 議題 3 | 時機本身已經是聽得到的事件 |
| 「空檔裡盾沿聲為零」（4.4） | 盟友也凍結 | **刪**：盾沿整場不停 | 盾沿是玩家跟拍的依據，更不該斷 |
| 假驟降（4.4 列第二批） | 未做 | **不做** | 每次交接都無縫之後沒有「假」可言 |
| 揮砍拍、命中拍、低音拍、招架、號令、氣條、攻位、三段難度、暖身三輪 | — | **全部不動** | 這些本來就不靠靜默 |
| 一句話核心（第 1 節）「鼓一斷就是你必中的一擊」 | — | 改成「最響的那一擊落下，就是你必中的一擊」 | 文字跟著 |

規則層的改動只有三處：
- 新常數 `COVER_MODE`【新】（布林，預設 `true`；`false`＝v2 原本的空檔）。
- 事件 `gap`、`pre_gap` 名稱保留（聲音與畫面已經照這兩個名字接），另加別名事件 `cover`【新】與 `gap` 同時發；`COVER_MODE` 下 `pre_gap` 的 `knocks` 只在教學輪帶值（1.3 議題 3）。
- 提示文字的 `gap` 相關條目加 `COVER_MODE` 分支，不得出現「斷」「停」（照木馬之夜 7.4 的做法與測試）。

`GAP_LEN`、前沿寬限、`LEADER_HITS_PER_CYCLE`、所有 `STRIKE_`、`PARRY_`、`STAMINA_` 常數值都不變。v2 第 16 節的測試清單不用重寫，只要兩種模式各跑一次。

### 1.2 聲音與畫面（`COVER_MODE`）

| | 聲音 | 畫面 |
|---|---|---|
| 重合擊 | 各層第一拍同時落下，加兩位盟友重擊盾面的一聲（300～1200 Hz 厚擊，喇叭聽得到），突出量目標 ≥ 12 dB【假設，待量；沿用木馬之夜 7.5 的門檻】 | 兩位盟友同時把矛桿砸在盾面上；爐火一竄 |
| 餘韻 0.6 秒 | 節奏線的殘響送量在窗的前半推高，窗結束前收完；量到的餘韻長度中位 0.5～0.8 秒（同木馬之夜 7.5） | 杯盤與塵土跳起後落下，長度讀 `GAP_LEN`；準心收成一點（射箭段）或變手掌形（近戰段，推擊可用時） |
| 盾沿 | 2.8～4 kHz 短響照敲，不停 | 盟友照敲 |
| 不准做的事 | 把鼓、盾沿、人聲任何一條整體壓低超過 3 dB | 全場凍結、變冷色 |

火光亮度若要表現危險程度，跟循環長度（實際速度）走，不跟相位走（同木馬之夜第 2 節的裁決）。求婚者每個循環逼近再被打退是敵人的行為，不是音樂的鐘，照 v2 不動。

### 1.3 兩個議題的裁決

**議題 2：掩護窗裡，剛被招架的人身上還亮著白光，左鍵算推擊還是反擊？**
裁決：**照 v2 第 7.3 節已審定的條文，一個字不改。** 那一節已經寫明：空檔內左鍵一律是推擊；反擊窗順延到空檔後第一個揮砍拍；窗內推了被招架的那個人，推擊照常結算、反擊窗取消，二擇一。把「空檔」讀成「掩護窗」即可。
不採用初稿的「推擊 1 點加反擊 2 點＝3 點」：它打破 `LEADER_HITS_PER_CYCLE` 1 的上限，那個上限是 11/08 四席審議後為了擋住一輪秒殺頭目才加的。也不改按鍵。

**議題 3：重合擊前的空心木塊兩聲要不要留？**
裁決：**降為教學輔助，由現有的暖身與暗示階梯決定響不響，不另外發明規則。**
- 會響：射箭段第 0～3 輪；近戰暖身輪（標準 3 輪）；之後只有 `gap` 這條暗示升到第 2 階以上時（代表玩家連續錯過）才再響，成功一次就停。
- 其他時候不響。掩護窗前 0.3 秒節奏變亮照留，常數名沿用木馬之夜的 `COVER_BRIGHT_DB`【新，預設 4】，可調到 0。
- 理由：近戰段同時要顧揮砍、招架、號令，比潛行忙，開局不給預備會讓前幾輪的掩護窗白白過去；但一直給，玩家聽的是木塊不是鼓。

### 1.4 試驗場（v2 第 19 節的 12 個裡，要動的 3 個）

| 試驗場 | 改動 | 自動化檢查多量什麼 |
|---|---|---|
| `tap`（踩拍箭三分） | 面板加「模式：掩護／空檔」切換；掩護箭與踩拍箭的弓弦聲音量並排顯示 | 兩種模式下三種箭的分類結果逐箭相同（判定沒變的證明） |
| `shove`（推擊） | 同上切換 | 兩種模式下推擊結果相同 |
| `charge`（轉折） | 轉折那一輪也有重合擊，確認兒子遞矛的演出不被震波蓋掉 | 轉折輪發 `cover` 事件、無攻擊 |
| 新增 `cover`【新】 | 無敵人、循環固定；面板顯示重合擊突出量（dB）、餘韻長度、離下一次掩護窗幾秒 | 錄音工具兩項：突出量與餘韻長度；`COVER_MODE` 下任何 0.3 秒窗的整體音量不得比前後低超過 6 dB（沒有偷偷留空檔） |

## 2. 比箭 Risset 版

### 2.1 改什麼、留什麼

| 項目（`rules.js` 常數） | 現在 | 改成 | 理由 |
|---|---|---|---|
| 驟降（`heart.dropLen` 0.5） | p 跳回 0 的頭 0.5 秒不排任何心跳拍：心跳斷掉、全場靜止 | **定神窗**：同樣的 0.5 秒，但心跳照排。交接那一下各層心跳同時落下（一下很重的心跳），接著 0.5 秒準心最穩 | 心跳不該停 |
| 窗內的晃動 | `ampDrop` 0.0005；沒有拍所以沒有心跳的推力 | `ampDrop` 不變；窗內心跳的推力乘 `coverKick`【新，預設 0】 | 拍照排之後，不壓掉推力準心就穩不下來 |
| 求婚者起鬨的推力 | 驟降時乘 0 | 不變（窗內乘 0） | 判定不變 |
| 求婚者的人聲 | 驟降時噤聲 | **不噤聲**，音量照舊；是那一下重的心跳蓋過他們，不是他們閉嘴 | 全場突然安靜就是空檔 |
| 最快一層在循環尾端額外拉高（`heart.urgent` 0.75） | 有 | **`COVER_MODE` 下關掉**（照純鐘形音量） | 見 2.2 |
| 整體力度隨相位變大（`heart.tensionLo` 0.6） | p = 0 時 ×0.6、p = 1 時 ×1 | **`COVER_MODE` 下固定 ×1** | 見 2.2 |
| 上弦、謝帕德音階、彈道、12 孔、箭飛行奏主題、暗示階梯、循環逐輪縮短 | — | 不動 | 不靠靜默 |
| 假驟降（總綱第 9 節待發想第 2 項「假驟降 × 射箭」） | 未做 | **不做**（議題 4） | 見 2.3 |

新常數只有兩個：`heart.coverMode`【新】（預設 `true`）、`draw.coverKick`【新】（預設 0）。`dropLen` 名稱保留、值不變。

事件：`drop` 保留；另加 `cover`【新】同時發，帶 `{t, len}`。提示文字加分支，「心跳一停就放箭」改成「心跳重重落下的那一下之後，手最穩，這時放箭」，不得出現「停」「斷」。

### 2.2 初稿漏掉的接縫（一定要改）

比箭的心跳和木馬之夜不同：為了讓循環尾端「真的最急」，它把最快那一層額外拉高到 0.75，整體力度又隨相位從 0.6 漲到 1。循環重來時這兩個量會同時掉回去，落差大約 4 dB 以上。現版靠 0.5 秒的靜默把這個落差藏住（檔頭註解自己寫了「重來的接縫正好藏在這段靜默裡」）。
靜默拿掉之後，這個落差就是一個聽得到的接縫，等於用另一種方式把交接點指出來。木馬之夜在 11/07 稽核時修過同一種問題（節奏匯流排從 0.7 漲到 1.0，交接掉 3 dB）。
所以 `COVER_MODE` 下這兩個都要關，回到各層音量和恆定的純鐘形。代價是循環尾端不再特別響，「越來越急」改由三樣東西撐：循環逐輪縮短（現有 `cycleMul` 0.9）、準心晃動隨相位放大（現有）、求婚者起鬨（現有）。夠不夠急要真耳朵判斷。

### 2.3 兩個議題的裁決

**議題 1：那一下重的心跳在筆電喇叭上聽不聽得出來？**
裁決：採初稿選項 A 的一半。
- 做：重合的那一下除了低頻，疊一層 300～900 Hz 的聲音。畫面上對應的是弓臂與弦繃到底的一聲悶響【改編】，不是另外的提示音。驗收：錄音工具在原始與喇叭模擬下，這一下在 300～1200 Hz 比前 1 秒突出 ≥ 12 dB【假設，待量】。
- 不做：把求婚者的人聲低通或壓低半秒。那等於換個方式做出安靜。
- 不做：靠準心變色當主要提示（選項 B）。準心收成一點是呈現，留著，但不能是唯一的訊號。
- 初稿寫的「實測可保證」刪掉；沒有量過。

**議題 4：要不要做「沒有重擊的假交接」當陷阱？**
裁決：**不做。** 比箭一局 20～40 秒、只有一個決定，加陷阱是替一個單純的時刻加干擾。總綱第 9 節待發想清單的第 2 項一併撤掉。

### 2.4 聲音與畫面（`coverMode`）

| | 聲音 | 畫面 |
|---|---|---|
| 交接的重心跳 | 四層心跳同時落下＋300～900 Hz 弓臂悶響；音量由規則的拍音量決定，聲音層不另加 | 畫面邊緣隨心跳一縮；弓臂一震 |
| 定神窗 0.5 秒 | 心跳照打；人聲照舊；餘韻長度同大廳復仇的做法，中位 0.4～0.7 秒【假設，待量】 | 準心收成一點；結束時準心重新開始晃 |
| 窗外放箭 | 不變 | 不變 |

### 2.5 試驗場
比箭目前只有 `?debug`。加一個固定場景【新】：弓已拉滿、無限箭、不計分；面板顯示相位、目前晃動幅度（弧度）、離下一次定神窗幾秒、上一箭放在窗內或窗外與偏差；「模式：定神／驟降」切換。自動化檢查：
- 兩種模式下同一串放箭時刻，窗內／窗外的分類逐箭相同。
- `coverMode` 下任何 0.3 秒窗的心跳拍數 ≥ 1（心跳沒有停）。
- `coverMode` 下交接前後各 0.2 秒，各層音量平方和的差 ≤ 1 dB（2.2 的接縫確實不見了；門檻取自木馬之夜稽核修後的「交接結構上 0 dB」，留 1 dB 容許）。
- 程式玩家在窗內放箭的命中孔數，兩種模式相差 ≤ 1 孔（難度沒有被偷改）。

## 3. 和木馬之夜甲版、方向乙的關係

| | 木馬之夜（甲，已實作） | 大廳復仇（本檔） | 比箭（本檔） |
|---|---|---|---|
| 時機 | 掩護窗 `BLIND_LEN` 0.6 秒 | 掩護窗 `GAP_LEN` 0.6 秒 | 定神窗 `dropLen` 0.5 秒 |
| 窗裡做什麼 | 衝刺、暗殺 | 掩護箭、推擊 | 放箭 |
| 平常做什麼 | 踩著鼓點走 | 踩揮砍拍放箭、出矛、招架 | 瞄準、撐住 |
| 開關 | `T.COVER_MODE` | `COVER_MODE`【新】 | `heart.coverMode`【新】 |
| 共同的規矩 | 時間窗不搬；不把任何一條聲音整體壓低；提示不說「斷」「停」；預告音只當教學輔助；火光跟實際速度不跟相位；重擊突出與餘韻長度用同一套錄音檢查 | 同左 | 同左 |

三個原型對外可以用同一句話：**鼓聲（心跳）從不中斷，最響的那一下就是你出手的時候。**

**方向乙「換層」放不放進這兩個原型？**
- **比箭：不放。** 一局太短，而且它的手感是「撐住不動」，和換層的「跟著走」相反。
- **大廳復仇：只留接口，現在不設計。** v2 在最後一名頭目時，揮砍拍從第 1 層換到第 0 層（3 拍變 2 拍，盟友敲盾沿的間距變寬）。那一刻系統替玩家換了層。若換層試驗場證明「聽得出底下慢的那條進來了」，這裡可以改成玩家自己決定什麼時候換：早換，拍子疏、好踩但出手機會少；晚換，拍子密、機會多但容易亂。這會是終章最後一段的高潮。
- 進這一步的前提：`prototypes/layer-ride/` 試驗場關掉輔助後，使用者只靠耳朵能在喇叭上完成換層。沒過就不做，v2 現行的自動換層保留。

## 4. 實作順序建議（報告後；給總控，不是定案）

1. 大廳復仇照 v2 第 17 節第一批實作時，直接把 `COVER_MODE` 一起做進去（空檔的呈現本來就要重寫，一次做完比做兩次便宜）。
