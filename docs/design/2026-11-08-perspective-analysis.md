# 各遊戲用第幾人稱

日期：2026-11-08　範圍：主線、三個音樂原型、要重做的舊原型、尚未動工的概念
依據：各設計文件已寫的視角、11/02 引擎路線分析「換視角最貴」、11/07 本地試玩（喇叭聽不出核心聲音訊號，見 `docs/process/playtest-notes.md`）。

## 1. 結論

**整個系列統一用第一人稱。** 有三處要特別處理：
- 大廳復仇：維持在門檻前小範圍走動，不開放整個大廳。
- 岸邊點名：用固定鏡頭。
- 斯庫拉與卡律布狄斯：還沒定。

理由：這個系列的核心是「用耳朵玩」。第一人稱時，聽的位置就是看的位置，左右聲道直接對應方向。第三人稱的鏡頭在角色背後，聲音要從鏡頭算還是從角色算會互相打架，聽聲辨位就變模糊。

## 3. 連帶規則

1. **畫面和旁白不衝突**：鏡頭用第一人稱，故事旁白照 `docs/game-text.md` 用說書人第三人稱（「奧德修斯……」），像吟遊詩人在講你正在演的故事；提示照舊用第二人稱或不用人稱。
2. **喇叭也要聽得出來**：第一人稱很依賴耳機。11/07 用喇叭試玩，驟降、慢低音、腳步合拍都聽不出來。關鍵訊號不能只靠左右聲道與低頻：音色、音量起伏、靜默都要在喇叭上成立，左右聲道只當加分。
3. **搬 Unity 共用一套操作**：統一第一人稱，各款都能沿用主線現成的第一人稱控制（`FirstPersonPlayer`），只改移動範圍與按鍵。
