## 1. 一句話核心

**鼓聲不再只是「等它停」的時鐘，而是你弓弦的掩護：空檔最穩、踩在鼓點上次穩、鼓點之間最晃而且弓弦聲會把人引過來；拉著弓連續踩拍就能蓄出一箭穿桌板、穿兩人。**

### 1.1 它怎麼回答「被動」

現行版本一輪 7.2 秒裡，玩家能做決定的時間只有 0.6 秒空檔（放一箭）加上低音拍按一下 Q；其餘 6 秒都是等攻擊來、再反應。這份規格把整個循環都變成可以行動的時間，但每個時刻的「品質」不同，所以玩家要**選**在哪個拍上花掉有限的箭與注意力，而不是等唯一正確的時刻。

### 1.2 玩家每個循環要做的選擇（主動決定清單）

| # | 選擇 | 選項 | 代價與回報 |
|---|---|---|---|
| 1 | **這一輪在哪種拍上放箭** | 空檔箭（最穩、不暴露）／踩拍箭（小偏差、不暴露）／亂射（大偏差、暴露、打不穿桌板） | 空檔每輪只有一次；踩拍可以一輪好幾箭但要跟拍；亂射是用箭和安全換「現在就射」 |
| 2 | **要不要拉著弓蓄力** | 按住左鍵，連續幾個可踩拍準心都對著人 → 下一箭穿透 | 拉著弓走得慢、視野略收；按 Shift 閃避會鬆弦歸零。最高速時攻擊會來，你得決定「放掉蓄力去閃」還是「賭兒子的盾或喝令，把這一箭射出去」 |
| 3 | **射哪個部位** | 頭（小、直接倒）／胸（穩、桌板會擋）／下盤（他跪下、桌板掉、這輪不再出手） | 頭只有空檔或踩拍打得到；下盤是控場，不是擊倒 |
| 4 | **射誰** | 四名頭目之一／正在預備出手的人（射倒或射跪就取消那一擊）／擋在前面的人 | 先下手就不用躲，但那一箭如果不穩，等於白送又暴露 |
| 5 | **低音拍下什麼令** | 滾輪選：舉盾（兒子）／取箭（兒子跑去撿）／喝令（你的聲音讓出手的人遲疑）／擲矛（撿到矛才有） | 同一個低音拍只能下一道令；兒子去取箭時就沒人舉盾 |
| 6 | **用什麼擋這一擊** | 閃避／屏息（撲上來的）／盾／喝令／先下手射倒他 | 閃避最保險但毀蓄力；屏息不毀蓄力還讓準心更穩，但有 4 秒上限 |
| 7 | **走位** | 守在門檻正中／走去撿箭、撿矛／繞到能把兩人排成一線的角度（穿透箭用） | 離開中央，側邊的攻擊更難看見 |

每輪至少 4 個決定（1、3、4、5），其餘依局勢。現行版本每輪只有 1 個決定（空檔射誰）加 2 個反應。

## 3. 和 Risset 節奏的關係

| 動作 | 綁什麼 | 為什麼還是「以音樂切入玩法」 |
|---|---|---|
| 空檔箭 | 空檔（驟降 0.6 秒） | 鼓一斷，全場靜止，手最穩。沿用 |
| 踩拍箭 | **可踩拍**：當下最響的那一層 Risset 鼓（前半循環是手拍層、後半是框鼓層；規則 `tapLayerAt(p)` 給） | 弓弦聲落在鼓點上就被鼓吞掉，跟木馬之夜「腳步踩鼓點被蓋過」是同一條聽覺邏輯 |
| 亂射 | 拍與拍之間（自由，但有代價） | 鼓與鼓之間大廳是空的，弓弦一響全場聽得見 → 有人朝聲音擲矛 |
| 蓄力拍 | 可踩拍：拉著弓時每個可踩拍判一次「準心有沒有對著人」 | 拉弓的手跟著鼓穩住；你在用鼓數拍子 |
| 低音拍指令（盾、取箭、喝令、擲矛） | 低音拍 ±0.15 秒 | 慢低音是「說話的節奏」：喊給兒子聽、喊給敵人聽，都壓在最低的那一聲上 |
| 瞄準、轉身、走路、撿東西（E） | 完全自由 | 不綁拍，讓玩家隨時有事做 |
| 閃避（Shift）、屏息（空白鍵） | 綁攻擊命中時刻（攻擊本身落在最高速） | 沿用 |

**沒有呈現的拍不拿來判定**：可踩拍只取最響那一層，而且規則層會把這些拍送給畫面層（爐火跳一下）和聲音層（這一層的鼓本來就最響，200～4000 Hz 的手拍與框鼓在喇叭也聽得到；低鼓層與金屬層從來不會是可踩拍）。

可踩拍的間距（標準 7.2 秒）：循環開頭 0.37 秒 → 中段 0.26 秒（手拍層）→ 交棒到框鼓層 0.52 秒 → 結尾 0.37 秒。空檔前最後一拍離空檔約 0.37 秒，所以「踩完最後一拍、空檔再射一箭」是順的。

## 4. 狀態機與一個循環的流程

### 4.1 弓（玩家）

```
IDLE ──按住左鍵──▶ DRAWING（走速減半、FOV −5°、每個可踩拍判一次 aimed，對著人 streak+1、沒對著人 streak 歸零）
DRAWING ──拉超過 DRAW_MAX──▶ TREMBLE（streak 歸零、偏差改用亂射值；放開才解除）
DRAWING ──按 Shift──▶ IDLE（鬆弦不射、箭不扣、streak 歸零；閃避照常）
DRAWING/IDLE ──放開左鍵（或 IDLE 時點一下）──▶ RELEASE
RELEASE：判定放箭時刻 shootAt 屬於
   空檔   → kind=gap   偏差 0        不暴露
   可踩拍 → kind=tap   偏差 SPREAD_TAP 不暴露
   其他   → kind=off   偏差 SPREAD_OFF 暴露（EXPOSE_LEAD 後有人擲矛）、不能穿桌板
   streak ≥ STREAK_PIERCE 且 kind≠off → pierce=true（穿桌板、穿第二人）
   streak ≥ STREAK_QUICK            → 下一箭裝填只要 BOW_QUICK（連箭）
RELEASE ──▶ RELOAD（BOW_RELOAD 或 BOW_QUICK）──▶ IDLE
```

### 4.2 部位判定（放箭時 traceShot 回傳命中高度 y）

| 部位 | 高度帶 | 效果 |
|---|---|---|
| 頭 | HEAD_Y0 1.5～1.8，水平半徑 HEAD_R 0.14（比身體 0.32 小） | 直接倒下，桌板擋不住 |
| 胸 | CHEST_Y0 1.0～1.5 | 無桌板：倒下。有桌板：箭釘在桌板上（hp −1），第二箭才倒；穿透箭一箭倒；亂射的箭彈開（hp 不減） |
| 下盤 | 0.2～1.0 | **跪下**（KNEEL）：到下一個空檔結束前不前進、不出手（已排的攻擊取消）、桌板掉地；跪著的人任何部位中箭都倒 |

穿透箭：第一人倒下後，沿原方向在 PIERCE_RANGE 內再找一人，第二人視同「胸」判定（有桌板也穿）。

### 4.3 低音拍指令

```
滾輪：選 CMD ∈ {shield（預設）, fetch, shout, spear（手上有矛才出現）}
右鍵（或 Q）在低音拍 ±BASS_WIN(+LATENCY_GRACE) 內：
   shield → 忒勒馬科斯舉盾到下一拍後（沿用）
   fetch  → 忒勒馬科斯 FETCHING：跑去撿最近 FETCH_MAX 支地上的箭，FETCH_TIME 後在低音拍上回來交給你；期間沒有盾
   shout  → 正在預備（warned 且未命中）的攻擊 impact 延到下一循環同相位；冷卻 SHOUT_COOL 個循環；沒有人在預備 → shout_none，不進冷卻
   spear  → 朝準心擲矛（偏差 SPEAR_SPREAD_BASS）：普通求婚者倒下、頭目跪下＋桌板掉；矛落地可再撿
右鍵不在低音拍上：
   shield/fetch/shout → tele_miss（兒子慌、你的聲音破），TELE_LOCK 內不能再下令
   spear → 照樣丟（偏差 SPEAR_SPREAD_OFF，暴露）
```

忒勒馬科斯：`READY → SHIELD_UP（block 後 COOL 8 秒）| FETCHING（FETCH_TIME）→ READY`。

### 4.4 一個標準循環（7.2 秒）的文字流程

```
p=0.00  空檔開始（0.6 秒）：全場凍結、鼓斷。 玩家：放空檔箭（最穩；若上一輪帶著 streak≥3 進來 → 穿透；streak≥2 → 可連第二箭）
p=0.08  空檔結束，手拍層最響，可踩拍每 0.37 秒一下。 求婚者開始逼近（a=p²，很慢）
p=0.17  低音拍 #1（1.2 秒）。 玩家：下令（盾／取箭／喝令／擲矛）
p=0.1~0.5 玩家：遠距，踩拍箭命中率低 → 多半拉弓蓄力、走位、撿箭；或對最近的普通求婚者踩拍試射
p=0.50  低音拍 #2（3.6 秒）；手拍層交棒給框鼓層，可踩拍變稀（0.52 秒）再加速
p=0.6~0.75 求婚者明顯逼近（a=0.36～0.56），踩拍箭開始值得；蓄力若已滿 3 拍 → 選目標排一線
p=0.78  預備（WARN）：有人舉矛或蹲低（p≈0.9 命中）。 玩家：A 鬆弦閃避／B 屏息（撲上來的）／C 相信盾／D 下一個低音拍喝令／E 現在就踩拍把他射倒
p=0.83  低音拍 #3（6.0 秒）：最後一次下令機會（喝令要在這裡）
p=0.90  命中結算。 之後 2 個可踩拍（0.37 秒）→ 空檔前最後一拍
p=0.94  pre_gap 預告（木魚「叩、叩」）。 玩家：決定空檔箭射誰、哪個部位
p=1.00  交接：下一輪長度定案（越危險越快）
```

## 5. 數值表

命名沿用 `T`。括號內為單位；「輕鬆／標準／殘酷」三欄。沒列的常數維持現值（`GAP_LEN 0.6`、`BASS_PERIOD 2.4`、`BASS_WIN 0.15`、`LATENCY_GRACE 0.05`、`EXPOSE_LEAD 1.3`、`SPREAD_OFF 0.2/0.2/0.3` 等）。

| 常數 | 輕鬆 | 標準 | 殘酷 | 為什麼 |
|---|---|---|---|---|
| `TAP_WIN`（秒，±） | 0.08 | 0.06 | 0.04 | 可踩拍間距 0.26～0.52 秒；窗太寬亂射也會「碰巧踩上」。標準的覆蓋率約 35～45%（第 14 節）|
| `TAP_LATE`（秒，晚按多給） | 0.05 | 0.04 | 0.03 | 滑鼠到音訊的延遲，和 `LATENCY_GRACE` 同理 |
| `TAP_MIN_GAIN` | 0.45 | 0.45 | 0.45 | 最響層的音量門檻，保險用：低於它的拍不當可踩拍（正常情況最響層永遠 ≥ 0.5）|
| `SPREAD_TAP`（弧度，±） | 0.04 | 0.05 | 0.06 | 10 公尺外 ±0.5 公尺，身體半徑 0.32 → 遠距踩拍約五成命中、4 公尺內近乎必中；逼玩家在最高速（最近）時射 |
| `SPREAD_TAP_BREATH`（倍率） | 0.5 | 0.5 | 0.5 | 屏息時踩拍偏差減半：古典射手的憋氣，也是「不鬆弦的擋法」的回報 |
| `BOW_RELOAD`（秒） | 0.5 | 0.5 | 0.5 | 比最密的可踩拍（0.26）長，所以踩拍連射最快是隔一拍一箭 |
| `BOW_QUICK`（秒） | 0.25 | 0.25 | 0.25 | 連箭：streak≥`STREAK_QUICK` 放箭後，下一箭裝填只要這麼久；空檔 0.6 秒內放得下兩箭 |
| `STREAK_QUICK`（拍） | 2 | 2 | 2 | 連箭門檻 |
| `STREAK_PIERCE`（拍） | 2 | 3 | 3 | 穿透門檻：3 拍約 1 秒拉弓，正好是「從預備到命中」的長度，玩家得決定要不要撐過那一下 |
| `STREAK_MAX`（拍） | 3 | 3 | 3 | 到頂不再加 |
| `DRAW_MAX`（秒） | 4.8 | 3.6 | 2.4 | 拉太久手抖（TREMBLE）；標準 = 1.5 個低音拍，夠跨過一次攻擊但撐不過一輪 |
| `DRAW_WALK`（倍率） | 0.6 | 0.5 | 0.5 | 拉弓時走速（2.2 → 1.1 公尺/秒）|
| `DRAW_FOV`（度） | −5 | −5 | −5 | 拉弓時視野略收；畫面層用，提醒「你正專注、側邊看不見」|
| `PIERCE_RANGE`（公尺） | 5 | 4 | 3.5 | 穿透後再找第二人的距離 |
| `HEAD_Y0`／`HEAD_R`（公尺） | 1.5／0.16 | 1.5／0.14 | 1.5／0.12 | 頭的帶與半徑；空檔或 4 公尺內踩拍才打得到 |
| `CHEST_Y0`（公尺） | 1.0 | 1.0 | 1.0 | 胸與下盤的分界 |
| `KNEEL_UNTIL` | 下一個空檔結束 | 同 | 同 | 跪下的長度不用秒數，用循環：越危險越快時自然變短 |
| `OFF_TABLE_BOUNCE` | true | true | true | 亂射打桌板彈開、hp 不減；去掉的話亂射和踩拍差距太小 |
| `EXPOSE_MAX_PENDING` | 1 | 2 | 2 | 同時最多幾支「因暴露引來」的矛在飛；超過的只發 exposed 事件不加攻擊，避免一出錯就被打成篩子 |
| `FETCH_TIME`（秒） | 2.4 | 2.4 | 2.4 | 取箭一趟 = 一個低音拍；去時沒盾 |
| `FETCH_MAX`（支） | 4 | 3 | 2 | 一趟撿幾支（離他最近的）|
| `SHOUT_COOL`（循環） | 1 | 2 | 3 | 喝令冷卻 |
| `SHOUT_DELAY`（循環） | 1 | 1 | 1 | 被喝住的攻擊推到下一循環同相位（下一輪會變兩擊）|
| `SPEAR_SPREAD_BASS`（弧度） | 0.03 | 0.03 | 0.04 | 低音拍上擲矛 |
| `SPEAR_SPREAD_OFF`（弧度） | 0.25 | 0.25 | 0.3 | 不在低音拍上擲矛，而且暴露 |
| `SPEAR_HOLD`（支） | 1 | 1 | 1 | 手上最多一支矛 |
| `SPEAR_DROP_ON_DODGE` | true | true | true | 閃過的矛落在 `DROP_ZONE`；被盾擋下的斷掉、打中你的不留 |
| `ARROWS` | 14 | 12 | 10 | 沿用 |
| `HP` | 4 | 3 | 2 | 沿用 |
| `CYCLE_BEATS` | 4 | 3 | 2 | 沿用 |

判定窗整理（秒）：空檔 0.6；可踩拍 −0.06～+0.10（標準）；低音拍 −0.15～+0.20；閃避 −0.35～+0.12；屏息 命中前 0.2 秒起。

## 6. 失敗與代價

| 情況 | 代價 | 上限／保護 |
|---|---|---|
| 攻擊命中（沒閃、沒屏息、沒盾、沒喝住、沒先下手） | 扣 1 血 | 同現行；一輪最多 2 擊（殘酷），`EXPOSE_MAX_PENDING` 另算 |
| 亂射 | 箭偏差大、打桌板彈開、1.3 秒後引來一矛 | 同時最多 `EXPOSE_MAX_PENDING` 支；落在空檔的延到空檔後 |
| 踩拍沒踩準（在拍窗外） | 等於亂射 | 第 1 次只有世界內回饋（弓弦聲清楚響起、附近的人轉頭）|
| 拉弓時按 Shift | 鬆弦、streak 歸零，箭不扣 | 這是設計上的「選擇代價」，不是懲罰 |
| 拉超過 `DRAW_MAX` | 手抖：streak 歸零、偏差改亂射值，直到放開 | 畫面準心大幅晃、弓臂抖；放開不扣箭 |

## 8. 暗示階梯

|---|---|---|---|---|---|
| `tap` | 失敗：空檔外放箭落在拍窗外。成功：踩拍箭 | 踩拍時弓弦聲被鼓吞掉；沒踩到時弓弦「嗡」一聲在大廳迴盪，最近的求婚者「嗯？」轉頭 | 爐火在每個可踩拍跳一下；踩到時準心收縮一瞬；沒踩到時準心抖開 | 「跟著爐火跳的那一下放箭，弓弦聲會被鼓蓋過。」 | 「爐火每跳一下就是一個鼓點，在那一瞬間放開滑鼠左鍵；鼓與鼓之間放箭會被聽見。」|

### 10.3 「越危險越快」怎麼接

循環縮短時可踩拍間距同比縮短（2 拍 4.8 秒：0.25 → 0.17 → 0.35 → 0.25 秒），拍窗不變 → 踩拍相對變寬鬆、蓄力三拍只要 0.6 秒，但攻擊每 4.8 秒就來兩次、空檔箭的頻率也變高。意思是：越快的局面，射箭越自由、躲攻擊越緊。`KNEEL_UNTIL` 用循環算所以自動變短；`SHOUT_COOL` 也是。殘酷本來就 2 拍，開關無效（沿用）。

## 11. 可量化的目標

三個程式玩家（`vengeance.test.js` 新增），標準難度、每段 50 局、幀率 8～15 fps，熟練度 1.0 與 0.6 各跑一次（0.6：40% 的低音拍忘了按、40% 的攻擊反應慢 0.3 秒、40% 的踩拍晚 0.08 秒）。

| 策略 | 做法 | 目標（熟練 1.0） | 目標（熟練 0.6） |
|---|---|---|---|
| 甲・保守 | 只在空檔射胸、每個低音拍舉盾、預備就閃避、箭完才走去撿 | 勝率 ≥ 48/50，用時約 44～48 秒（= 現行完美玩家 46 秒） | 勝率 ≥ 44/50 |
| 乙・主動 | 拉弓蓄力三拍穿透拿桌板的頭目；p>0.6 踩拍射最近的頭目；空檔射頭；預備時若 streak≥2 用喝令或屏息、否則閃避；箭 ≤ 4 且地上 ≥ 3 支時取箭 | **勝率 ≥ 48/50，用時 ≤ 30 秒（比甲快 30% 以上）**；箭用量 ≤ 甲 | **勝率 ≥ 44/50、用時 ≤ 36 秒**（不能比甲更危險）|
| 丙・亂射 | 裝填好就射最近的頭目，不管拍；其餘同甲 | **勝率 ≤ 25/50**，且踩拍比例 ≤ 45% | — |

判準：乙在熟練 1.0 與 0.6 都要「明顯更快、不更危險」；丙要明顯更差。任一條不成立 → 調 `TAP_WIN`、`SPREAD_TAP`、`OFF_TABLE_BOUNCE`、`EXPOSE_MAX_PENDING`，再不成立就算設計失敗，回報使用者。

另外量：乙的「每輪決定數」（放箭種類切換、指令切換、部位切換）平均 ≥ 3；甲 = 1。

## 12. 測試清單（規則層）

1. `tapLayerAt(p)`：四層時 p<0.5 回 2、p≥0.5 回 1；回傳層在該 p 的 `layerGain` 是四層最大。
2. `tapBeatsBetween(a, b)` 只含該層的拍、不含空檔內的拍、不含音量 < `TAP_MIN_GAIN` 的拍；間距在標準落在 0.26～0.52 秒。
3. 放箭在可踩拍 −TAP_WIN～+TAP_WIN+TAP_LATE 內 → `shoot.kind === 'tap'`、偏差 ≤ SPREAD_TAP、不發 `exposed`；拍窗外 → `off`、發 `exposed`。
4. 空檔內放箭 kind `gap`、偏差 0；同一空檔第二箭只有在 streak≥STREAK_QUICK 放了第一箭後才允許，否則 `bow_busy`。
5. `BOW_RELOAD` 內再放箭 → `bow_busy`、不扣箭；`BOW_QUICK` 只生效一次。
6. 拉弓：每個可踩拍判 `traceShot`，對著人 streak+1（上限 STREAK_MAX），沒對著人歸零；非可踩拍的時間不改 streak。
7. 拉超過 `DRAW_MAX` → `tremble` 事件、streak 0、放箭偏差 = SPREAD_OFF 但仍不暴露（弓弦聲判定看放箭時刻）；放開後下一次拉弓恢復。
8. 拉弓中 `dodge` → `draw_cancel`、箭數不變、streak 0、閃避照常生效。
9. 屏息中踩拍放箭偏差 ×SPREAD_TAP_BREATH。
10. 部位：同一名有桌板的頭目，胸口中箭 hp−1 且 `shield_hit`；頭中箭直接 `down`；下盤中箭 `kneel`（桌板掉、該人已排攻擊 cancelled、到下一空檔結束 `suitorPos` 不前進），跪著任何部位中箭 `down`。
11. 穿透：streak≥STREAK_PIERCE 的 gap／tap 箭對桌板 → 直接 down；後方 PIERCE_RANGE 內排成一線的第二人也 down（一箭兩個 `down` 事件）；超出距離不穿。
12. 亂射打桌板 → `bounce`、hp 不變、箭落地可撿。
13. 暴露：同時未結算的暴露矛 ≥ EXPOSE_MAX_PENDING 時，再暴露只發 `exposed`、不加攻擊。
14. 指令：`cmd` 在 shield／fetch／shout／spear 間切換；沒矛時切不到 spear；低音拍上右鍵執行所選，錯拍 → `tele_miss` 與 TELE_LOCK（spear 例外：照丟、偏差 SPEAR_SPREAD_OFF、暴露）。
15. 取箭：`fetch_start` 後 `tele.until` 清空、FETCH_TIME 內攻擊不會 `block`；FETCH_TIME 後 `fetch_done` 箭 +min(FETCH_MAX, 地上箭數)、對應 floorArrows 移除；地上沒箭 → `fetch_none`、不進 FETCHING。
16. 喝令：有 warned 未結算的攻擊 → 該攻擊 impact += 該循環長度（下一循環同相位），`shout_ok`，冷卻 SHOUT_COOL 循環；沒有 → `shout_none` 不冷卻；冷卻中 → `shout_busy`。被推遲的攻擊下一輪和原排程共存（該輪兩擊）。
17. 矛：閃過（dodge_ok）的 spear 攻擊落地 `floorSpears` 一支在 DROP_ZONE；block／hurt 的不落地；E 撿起 `spearHeld = 1`，第二支撿不起；擲中普通人 down、頭目 kneel＋桌板掉；沒中落地可再撿。
18. 第 0 循環：可拉弓、streak 會累積、放箭照常扣箭（第一箭的選擇由玩家負責）、不出手。
19. 暗示階梯：`tap`、`draw`、`zone`、`cmd`、`fetch`、`shout`、`spear` 各自 2 次 → level 2、3 次 → level 3、成功一次 → 1；文字與第 8 節一致。
20. 三段難度把第 5 節的值正確覆寫；`KNEEL_UNTIL` 在動態循環下以實際交接長度算。
21. 聲音層契約：規則 `tapBeatsBetween` 的拍 ⊆ 聲音層排的拍；畫面層爐火事件和 `tapBeatsBetween` 一致（錄音工具加「爐火拍 vs 最響層拍」對照）。
22. 第 11 節三個程式玩家的勝率與用時。

## 13. 保留與拿掉

| 項目 | 處置 | 理由 |
|---|---|---|
| 空檔 0.6 秒、每輪一空檔箭最穩 | 保留 | 空檔仍是最好的一箭，只是不再是唯一的一箭 |
| 低音網格與舉盾 | 保留，變成預設指令 | 兒子的拍子不變，玩家多了選擇 |
| 攻擊落在最高速、閃避、屏息 | 保留 | 反應那一端不動，動的是行動那一端 |
| 12 支箭、HP 3、四名頭目、投降 | 保留 | 節奏感與長度已驗證 |
| 「空檔外放箭一律偏差 ±0.2、一律暴露」 | **改掉**：拆成踩拍（小偏差、不暴露）與亂射（大偏差、暴露、打不穿桌板） | 這是整份文件的核心改動 |
| 「一個空檔只能一箭」 | **改掉**：連箭例外 | 給蓄力一個空檔內的回報 |
| 桌板 hp 2 | 保留，加部位：頭不受擋、下盤讓他放開 | 讓桌板從「多射一箭」變成「怎麼射」的問題 |
| Q／右鍵舉盾 | **改掉**：右鍵 = 執行滾輪指令，預設仍是盾 | 一個節奏鍵承載四種選擇 |
| 撿箭只能自己走過去 | 保留，**加**兒子取箭 | 守門檻和補給變成取捨 |
| 暗示 `tele` | 改名 `cmd`（舊 key 相容） | 文字要提滾輪 |
| 求婚者擲出的矛消失 | **改掉**：閃過的落地可撿 | 多一種不花箭的攻擊手段，也是「閃避」的回報 |
| 刪：無 | — | 現行機制都留著，只擴充 |

## 14. 風險與未定

### 14.1 最可能壞的地方

1. **拍窗覆蓋率**：可踩拍間距 0.26～0.52 秒，標準拍窗 0.16 秒（−0.06～+0.10），覆蓋率循環中段最高約 60%、後半（真正要射的時段）約 35～43%。亂射「碰巧踩上」的比例若超過 45%，踩拍就沒意義。備案：(a) 拍窗再縮到 ±0.05；(b) 可踩拍改成**固定參考層**（整輪只認框鼓層，間距 0.74 → 0.37 秒，覆蓋 22～43%）；(c) 中段交棒時只認交棒後那一層。要用程式玩家丙驗證再決定。
2. **兩層交棒聽感**：p=0.5 手拍層交棒給框鼓層，可踩拍間距從 0.26 跳到 0.52。耳朵聽 Risset 是連續加速，但「可以射的拍」會突然變稀。爐火只跳可踩拍能補畫面，聲音上要本機真耳朵判斷會不會覺得被騙。
3. **按住左鍵拉弓 vs 點一下直接射**：點一下也會進 DRAWING 一瞬再 RELEASE；要定義「按下到放開 < 0.12 秒 = 點射，用按下時刻判拍」，否則點射永遠慢一截。
4. **選擇太多**：滾輪四個指令加三個部位加三種拍，第一局可能手忙腳亂。緩解：第 0～3 輪滾輪只有盾（取箭在第一次箭 ≤ 6 時解鎖、喝令在第一次被打中後解鎖、矛撿到才有）；暗示階梯逐個帶出。
5. **喝令的「利息」**反而讓人不敢用：下一輪兩擊對新手太兇。緩解：輕鬆難度被喝住的攻擊直接取消（SHOUT_DELAY = 取消），標準以上才推遲。
6. **蓄力期間的攻擊**：三拍約 1 秒、預備到命中 0.9 秒，幾乎一定撞在一起。這是故意的，但若測出玩家十次有八次選鬆弦閃避，蓄力就是擺設 → 把 `DODGE_EARLY` 內鬆弦改成「保留一格」。

### 14.2 要本機真耳朵判斷

- 喇叭上分不分得出「可踩拍那一層」和其他層；爐火跳動是否足以替代。
- 弓弦被鼓吞掉 vs 弓弦迴盪，兩者差距夠不夠大（目標 ≥ 20 dB，和木馬之夜腳步 28 dB 同級）。
- 你的吼聲壓過鼓會不會太吵、太現代；兒子「左邊！」是幫忙還是嚇人。
- 拉弓時 FOV −5° 會不會暈。

### 14.3 待使用者決定（附建議）

| 題目 | 選項 | 建議 |
|---|---|---|
| 可踩拍定義 | A 最響那一層（本文）／B 固定框鼓層／C 兩層聯集 | **A**，但先讓程式玩家丙跑過；覆蓋率 > 45% 就換 B |
| 亂射打桌板 | 彈開（本文）／照樣 hp −1 | **彈開**，否則亂射太划算 |
| 被喝住的攻擊 | 推遲到下一輪（本文）／直接取消／輕鬆取消、其餘推遲 | **輕鬆取消、其餘推遲** |
| 滾輪指令數 | 4（盾、取箭、喝令、矛）／3（去掉喝令，用屏息當「不鬆弦的擋法」）| **4**，但逐步解鎖 |
| 頭的半徑 | 0.14／0.18（更容易、頭射會變主流）| **0.14**，頭射留給空檔與近距離 |
| 第 0 循環拉弓 | 扣箭／不扣箭（練習）| **扣箭**，第一箭也是選擇；暗示用爐火就夠 |

## 15. 第一人稱與門檻限制下的表現

- 玩家仍只在門檻前 7×6 公尺內走動（`ZONE`），求婚者都在前方約 120°。拉弓時 FOV 再收 5°，所以蓄力 = 自願縮小視野，是第 1.2 節第 2 項代價的畫面表現。
- **看不到兩側**：預備出手的人若在視野外 → 該側火把閃一下（沿用）、3D 聲音、**忒勒馬科斯喊「左邊！／右邊！」**（喇叭也聽得出來的補償，第 7 節）、HUD 邊緣朝那側暗下（沿用木馬之夜 2.1 的做法）。
- **鏡頭不自動轉**：第一人稱不搶滑鼠。只有兩個例外：穿透箭的第二人倒下（0.3 秒慢動作，準心不動，用箭跡帶視線）、投降（鏡頭微抬，不剝奪控制）。
- 跪下、倒下發生在視野外時只有聲音（跪倒「唔」、桌板「哐」、倒地悶響）＋ HUD 頭目圖示變化，不轉鏡頭。
- 排一線穿透：玩家要自己側移一兩步，門檻前的走動範圍剛好夠（x ±3.5）；畫面在 streak=3 時把準心後方同一線上的第二人輪廓微亮 0.2 秒，提示「這一箭可以穿兩個」。
- 兒子固定站在你左後方 1.5 公尺，他的盾與指令圖示都在畫面左下角，和準心不打架。

## 16. 每個綁拍輸入的呈現

已併入第 8.1 節的表，一個動作一列（畫面、聲音、按對、按錯、沒按）。補充原則：

- 可踩拍只有一個畫面信號（爐火與門邊火把跳一下），同一個信號永遠代表「現在可以射」。
- 低音拍只有一個畫面信號（弓弦旁的所選指令圖示亮、兒子的盾反光），永遠代表「現在可以下令」。
- 空檔只有一個畫面信號（凍結泛藍、箭頭發光）。
- 三個信號的顏色不同：可踩拍 = 爐火橙、低音拍 = 盾的銅色、空檔 = 藍白。
- 錄音工具加兩項檢查：「可踩拍那一層在 200～4000 Hz 的突出量 ≥ 6 dB」、「踩拍弓弦 vs 亂射弓弦差 ≥ 20 dB」。

## 18. 對方向 B（近戰比例加大）的接口

**可以直接接的**：
- **部位與跪下**：B 若有近身終結，「跪下的人任何部位中招都倒」可直接當近戰的終結條件；桌板掉地也給近戰開路。
- **撿矛**：閃過的矛落地，A 拿來擲、B 拿來刺，同一個 `floorSpears`。
- **低音拍指令輪**：B 的「架勢」或「兒子上前」可以當第五格，判定、暗示、呈現全套沿用。
- **暴露表**：亂射暴露引矛的規則（`EXPOSE_LEAD`、`EXPOSE_MAX_PENDING`）可以照搬給 B 的「揮空暴露」。
- **攻擊取消**：射倒或射跪預備中的人會取消攻擊，B 的近戰擊中也走同一條。

**會衝突的**：
- **滑鼠左鍵**：A 把左鍵做成「按住拉弓、放開射」；B 很可能也要左鍵揮擊。解法：依距離自動切換（最近的人 < 2 公尺才是近戰），或滾輪多一格「換武器」；但距離切換會讓撲上來的人逼你在拉弓中途換手，蓄力會被吃掉，要討論。
- **注意力預算**：A 已把每輪決定推到 3～4 個；B 再加近戰時機（也落在最高速），同一時段會塞爆。建議合併時 B 的近戰只在「撲上來」（lunge）那一種攻擊上成立，擲矛仍交給 A 的閃避／喝令。
- **最高速的角色**：A 把最高速（p 0.75～0.95）做成「踩拍射近身敵人 + 擋攻擊」的高潮；B 大概也把這裡做成近戰高潮。兩者都要就會打架，要決定誰是主、誰是輔。
- **循環長度**：A 在越危險越快下「射越自由、躲越緊」；B 若需要揮擊動畫長度（例如 0.5 秒）則 2 拍 4.8 秒的循環會太擠。

一句話：A 的「跪下、撿矛、指令輪、暴露」四樣是公共建設，B 可以直接蓋；左鍵和最高速時段是兩邊都想要的地，要分。
