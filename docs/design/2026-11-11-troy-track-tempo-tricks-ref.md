# 參考：電影配樂〈Troy〉的「一直加速」四招（2026-11-11，總控整理）

來源：使用者貼上的 YouTube 影片說明（作者分析 Nolan《奧德賽》配樂〈Troy〉的加速錯覺；影片本身未看，以下只依說明的四個重點，用白話整理）【電影】。影片附的延伸主題：hemiola、3:4 複節奏、截斷式複節拍（truncated polymeter）。

起因：使用者 11/11 真耳朵與試聽回報——淡出的那層在重置時不夠小、同時只聽得到一層，重置聽得出來（`docs/process/playtest-notes.md` 末段）。

| 招 | 白話 | 對照我們現在 |
|---|---|---|
| 1. 改良的 Risset 節奏 | 好幾層同一個節奏、速度互為兩倍，慢層淡入、快層淡出，一直交棒 | 已有；但使用者聽到只有一層、淡出層在重置時還聽得到 |
| 2. 拿掉細分拍（dropped subdivisions） | 快到某個程度時，把最密的那層拍子抽掉，耳朵改抓下一層當「拍子」，感覺又重新加速一次 | 沒有。可能正是藏接縫的關鍵：重置那刻不是音量淡出，而是直接把最快那層拿掉 |
| 3. Hemiola（三對二重音） | 同樣的拍子，重音改成每 3 拍一組疊在每 2 拍一組上，聽起來像突然變快或變慢 | 沒有。可放在循環接縫附近轉移注意力 |
| 4. 音高上升（pitch riser） | 一個持續往上滑的音（也可做成 Shepard 音階那種永遠在升的聲音），讓整體「一直在往上衝」 | 沒有。我們只有節奏層，沒有持續上升的音高線 |

待設計席判斷：哪幾招放進下一版試聽（第 3.1 節 S 系列）、哪幾招和「最響的一擊」衝突。注意：音高上升是持續的聲音，要確認不會蓋過低音拍與警戒聲（總綱規則 13）。
