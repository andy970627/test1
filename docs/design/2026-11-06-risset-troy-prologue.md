## 2. 核心玩法（交接包，加出處標記）

- **類型**：心理節奏生存／潛行【改編】
- **氛圍**：諾蘭版《奧德賽》的特洛伊段落與配樂〈Troy〉【電影】；戰爭創傷（PTSD）【改編】
- **核心**：Risset 節奏，一種聽起來無限加速的聽覺錯覺，用來驅動敵人的感知【改編】
- **機制 A：相位盲區與致命一擊**：節奏越高頻，敵人感知越強。高頻時要按住屏息、不能動。最高頻淡出、接回最低頻的約 0.5 秒是盲區，可以衝刺或暗殺
- **機制 B：恐慌共振與反向操作**：敵人起疑時音樂失控加速，玩家不能跟著加快操作，要聽底層極慢的低音，用極慢的節奏輸入安撫；輸入太快就被發現
- **狀態機**：巡邏（約 10 秒一個加速循環）→ 警戒（高頻失真，進入反向操作）→ 盲區（0.5 秒判定窗）→ 追殺（音軌全部疊加，改成逃生）
- **介面**：沒有視覺提示，靠聽覺；極端加速時刻意讓畫面和介面延遲、加雜訊，讓視聽不協調

待確認：電影特洛伊段落的具體場景（木馬、城內夜襲）要用哪一段當舞台。

## 3. 音訊引擎取捨：Web Audio vs Unity＋FMOD

| 面向 | Web Audio（網頁） | Unity＋FMOD／Wwise |
|---|---|---|
| **節拍精準度** | 用音訊時鐘 `AudioContext.currentTime` 預先排程，精度到樣本級，和 Unity 的 `dspTime` 同一個層級；**不能用畫面幀**計時（同交接包的提醒） | 最精準，FMOD 有拍點回呼與同步工具 |
| **多音軌相位、變速** | 可以：多個音源各自排程，用增益節點交叉淡入淡出；Risset 的「加速＋淡出交接」用程式合成或預錄循環都做得到 | 可以，而且有現成的參數自動化、混音器，調起來快 |
| **音質與效果** | 內建濾波、殘響（卷積）、失真、立體聲定位；夠用但要自己組 | 專業混音、殘響、側鏈壓縮、即時參數，效果最好 |
| **延遲與穩定** | 依瀏覽器與裝置：Chrome 桌機約 10～30 ms；分頁在背景時計時會被降速；第一次要玩家點一下才能出聲 | 原生程式，延遲低且穩定 |
| **畫面掉幀的影響** | 聲音在獨立的音訊執行緒，畫面卡也不會亂拍（前提是用音訊時鐘排程） | 一樣不受影響 |
| **上架與報告** | 直接放 itch.io、點開就玩，和現有網頁連作同一套 | 要建置 WebGL；FMOD 的 WebGL 支援要另外設定，檔案大、載入慢 |
| **製作速度** | 現有原型都用它，代理可以馬上做、自動測試 | 要在你電腦上開 Unity 測，我這邊沒辦法實際跑畫面與聲音 |
| **之後移植** | 規則（節奏時間表、狀態機）寫在獨立模組，可以翻成 C#；聲音的實作要用 FMOD 重做 | 本來就在 Unity；但會綁在 FMOD 上（授權、工具鏈） |

**結論**：原型階段用 Web Audio 做得出交接包要的核心體驗（精準節拍、多軌交接、低音層），代價是混音質感和裝置差異。等玩法確定、要做正式版時再換 FMOD，屆時只重做聲音層。

>
> 機制 B：恐慌共振與反向操作（Paranoia Resonance）——敵人起疑時音樂打破規律、失控加速；玩家不能跟著加快，必須聆聽底層極慢速重低音，以極慢頻率輸入安撫指令；被高頻帶偏而輸入過快，就被發現。
>
> AI 狀態機：巡邏（約 10 秒循環平滑加速，避開高頻峰值）、警戒（急促高頻與失真，啟動反向操作）、盲區（高頻切斷重置的 0.5 秒，開放致命一擊判定窗）、追殺（所有音軌極速疊加，轉為逃生）。
>
> 技術注意事項：使用 FMOD 或 Wwise；在 Unity 實作時三個以上音軌的相位、音高、音量必須以 `AudioSettings.dspTime` 絕對時間同步，嚴禁 `Time.deltaTime`。極端加速階段刻意讓視覺特效與 UI 延遲或加雜訊，製造視聽不協調。

### 6.2 規則（數值都寫成常數，可以調）

- **循環**：週期 T＝10 秒；相位 p＝((音訊時間 − t0) ÷ T) mod 1。p 越大，聽起來越快。
- **感知範圍**：r(p)＝2 ＋ 8 × p²（公尺）；警戒時 ×1.3。視野是正前方 ±60°；另外聽得到 r(p) 範圍內的聲音。
- **盲區**：p 從接近 1 跳回 0 之後的 0.5 秒，所有衛兵的感知是 0。
- **屏息**：按住空白鍵就不出聲，但不能移動；最多 6 秒，超過會大口喘氣，等於在原地發出一次大聲音。
- **移動**：p＞0.6 時，在任何衛兵的 r(p) 內移動就立刻被發現，進入追殺。p≤0.6 時，在範圍內移動會讓疑心上升。
- **衝刺**：只能在盲區裡使用（Shift），快速移動 3 公尺。
- **致命一擊**：盲區內、在衛兵背後 1.5 公尺內按 E，衛兵倒下；盲區外按 E，那名衛兵立刻起疑。
- **起疑（警戒，機制 B）**：疑心滿了 → 那名衛兵進入警戒。上層節奏失控加速、加失真；底層有一條固定週期 2.4 秒的低音。
  - 安撫：在低音拍點的 ±0.15 秒內按 Q，連續 4 次成功 → 回到巡邏。
  - 按太快（兩次間隔不到 1 秒）或偏離拍點 → 追殺。
  - 8 秒內沒有完成安撫 → 也進入追殺。
- **追殺**：所有音軌疊加。躲進暗處（陰影區）並在一整個循環內不動，就擺脫；被追上（1 公尺內）就失敗。
- **視聽不協調**：p＞0.8 時，畫面上的提示與特效刻意延遲約 0.15 秒，並加雜訊。

### 6.3 三個代理之間的介面

**`risset.js`（規則，UMD 全域 `RissetRules`，Node 可測）**
- `createLevel(opts)` 會回傳遊戲物件（game）。
- `game.step(audioTime, input)`：以音訊時鐘的絕對時間推進，不用畫面的 dt。
- 輸入 `input`：`{yaw, mx, mz, breath, dash, takedown, calm}`。其中 `dash`、`takedown`、`calm` 是只維持一幀的按下事件；`breath` 是按住的狀態。
- 狀態：
  - `phase`：`'intro'`｜`'play'`｜`'fail'`｜`'win'`（開場／遊玩／失敗／勝利）
  - `zone`：0～4
  - `cycle`：`{T, t0, p, blind, index}`
  - `bass`：`{period, nextBeat}`
  - `player`：`{x, z, yaw, breathing, breathT, hidden}`
  - `guards`：每個 `{id, x, z, yaw, state, susp, calm}`，`state` 是 `'patrol'`｜`'suspicious'`｜`'hunted'`｜`'down'`（巡邏／起疑／追殺／倒下）
  - `alarm`：0～1，給音訊用的失控程度
  - `hunted`：是否在追殺中
  - `level`：關卡資料，牆、陰影區、路線、木馬、城門
- 事件 `game.out`：`{type:'msg'|'sfx'|'hint', a}`，畫面層每幀取走。
- 常數 `T`：第 6.2 節的所有數值。

**`audio.js`（聲音，UMD 全域 `RissetAudio`）**
- `createAudio(ctx, {T, t0})`：Risset 節奏。多層打擊各自加速一倍，用鐘形增益交叉淡入淡出，聽起來無限加速。用 `ctx.currentTime` 預先排程，**不能用畫面計時**。
- `update(state)`：讀 `cycle`、`alarm`、`hunted`、`bass`，調整失控層、失真、低音層。
- `cue(name)`：音效，例如屏息、喘氣、門閂、倒地、警鐘。
- `now()`：回傳音訊時間。規則和聲音要用同一個 `t0` 與 `T`，相位才會一致。

**`index.html`（畫面與輸入）**
- three.js 夜晚的特洛伊：木馬、神殿廣場、窄巷、城門、陰影區、衛兵（拿火把）。
- 每幀：取 `audio.now()` → `game.step(...)` → 畫面 → `audio.update(game)` → 取走 `game.out`。
- 介面極少：屏息計量、提示行，以及 p＞0.8 時的延遲與雜訊。

## 7. 音樂性（11/06 使用者選定：兩者兼顧）

**原則**：玩法要靠的功能層（Risset 打擊、警戒時的慢低音）維持乾淨、不改時間；音樂層疊在上面，照同一套規則走：
- **盲區時一起靜音**：鼓點斷掉的那半秒，音樂也停，所有聲音都休止，玩家聽到的是一個明確的空檔。
- **避開關鍵頻段**：音樂層不放在打擊的主要頻段，也不放在低音拍點那一帶；警戒時音樂層退後，讓慢低音最清楚。
- **跟同一個循環走**：相位 p、週期 T 和規則一致。
- 全部原創、程式合成；電影配樂〈Troy〉只參考氛圍【電影】，不使用。

| 元素 | 做法 | 出處 |
|---|---|---|
| **謝帕德音階** | 音高版的無限上升錯覺：多個八度的正弦或柔和音色一起上滑，用鐘形音量交叉。一個循環升一個八度，和無限加速的節奏同步，p 越大越緊繃，盲區時斷掉、從底部重來 | 【改編】 |
| **主題動機** | 用古希臘調式（例如多利安或弗里吉安）寫 4～8 個音的短旋律，在盲區剛結束、進入低頻時出現一次，像在說「可以走了」。之後其他章用它當創傷的閃回 | 【改編】 |
| **低吟與合唱層** | 持續的男聲低吟（類母音合成），加上偶爾的合唱和弦；撐起情緒，放在中低頻 | 【改編】 |
| **分區編曲** | 木馬腹中：心跳＋鼓。神殿廣場：加低吟。窄巷：加謝帕德音階。城門：全部疊上，主題動機完整出現。勝利時城門大開，主題用號角完整奏出 | 【改編】 |

## 8. 動態節奏、視覺與聲音互動（11/07 使用者選定）

### 8.1 越危險越快【改編】

固定 10 秒一個循環太長：自由移動只佔約 6%，大多時候在等。改成循環長度跟著危險程度變化。

| 情況 | 目標循環長度 |
|---|---|
| 附近沒有衛兵（最近的衛兵超出感知範圍兩倍） | 12 秒 |
| 衛兵靠近 | 依距離平滑縮短，最短 6 秒 |
| 警戒 | 4 秒 |
| 追殺 | 3 秒 |
| 區域基準 | 每往城門一區，目標長度 ×0.9 |

- **盲區固定 0.6 秒**：速度只改變盲區出現的頻率，不改長度。
- **平滑變化**：循環長度每秒最多改變 20%，不會突然跳動。相位以累加方式推進：p += dt ÷ T(t)。
- **警戒時的盲區**：快速循環的盲區暫停，改成每兩個低音拍之間正中央有 0.6 秒的安靜，可以移動；安撫和移動不衝突，聲音檢查也一致。
- **節拍唯一來源**：規則模組是節拍的唯一來源，聲音與畫面都跟它走。

### 8.2 視覺（新手輔助，第二區之後淡出）【改編】

| 元素 | 內容 |
|---|---|
| 盲區的「凝結」 | 鼓點斷掉的 0.6 秒，畫面褪成冷灰、火焰停住、塵埃懸在空中 |
| 世界隨拍跳動 | 火把的火焰、地上塵土、木馬的木板跟著鼓點震動；拍子越快越躁動 |
| 月亮相位鐘 | 月亮一個循環轉一圈、越接近盲區越紅，抬頭就能預判 |

- 強度：第 0、1 區 100%，第 2 區 50%，第 3、4 區 0%，逼玩家改用耳朵。
- 實驗開關可以強制全開或全關。

### 8.3 聲音互動【改編】

| 元素 | 內容 |
|---|---|
| 腳步合拍掩護 | 移動時每 0.45 秒一步。踩在鼓點 ±0.08 秒內，腳步被鼓聲蓋過，不出聲；不合拍的腳步會出聲，衛兵聽得到（範圍 2.5 公尺），讓他疑心上升 |
| 安撫變成哼唱 | 按 Q 時哼出主題動機的下一個音：對拍時旋律延續，錯拍時走音，安撫成功等於唱完一句 |
| 3D 聽聲辨位 | 每名衛兵自帶腳步與呼吸聲，用 HRTF 立體聲定位，戴耳機聽得出方向與遠近 |
| 門閂奏出主題 | 推門閂每推進八分之一，就奏出主題動機的一個音；推滿正好奏完整段 |

### 8.4 三個代理之間的介面（在 6.3 之上新增）

**規則 `risset.js`**
- `game.cycle` 新增 `T`（目前循環長度）、`targetT`、`anchor:{t, p, T}`（本幀的音訊時間、相位、長度）。聲音層用 p(t)＝anchor.p＋(t − anchor.t) ÷ anchor.T 外推約 0.5 秒來排程。
- `game.cycle.blind` 的定義改為：相位剛跳回 0 之後的 0.6 秒（以秒計，不隨 T 變）；警戒時改成「兩個低音拍之間正中央的 0.6 秒」。
- 匯出 `beatPhases(k, n)` 等 Risset 拍點公式：拍點公式從聲音層移到規則層，兩邊共用。另外匯出 `beatsBetween(a, b, game)`，回傳 [a, b) 內的所有拍點（含層別）。
- 腳步：新增事件 `sfx:'step_masked'`／`sfx:'step_loud'`，附帶 `{x, z}`；不合拍的腳步會進入衛兵的聽覺判定。
- 安撫：事件 `calm_ok`／`calm_bad` 附帶 `index`（這是第幾個對拍）。
- 門閂：推進每 1/8 發出事件 `latch_step`，附帶 `index` 0～7。
- `game.visualAid`：0～1，依區域決定強度（0、1 區＝1，2 區＝0.5，其後＝0），實驗開關可以覆寫。

**聲音 `audio.js`**
- 依 `cycle.anchor` 外推排程，改用規則匯出的拍點公式。
- 腳步音（被掩蓋時很小聲）、哼唱（依 `calm_ok.index` 唱主題的第幾個音，`calm_bad` 唱走音）、門閂音符（依 `latch_step.index`）。
- 衛兵 3D：`setListener({x, z, yaw})` 加上每名衛兵的 PannerNode（HRTF），衛兵移動時發出腳步、平時發出呼吸聲。

**畫面 `index.html`**
- 盲區凝結、隨拍跳動、月亮相位鐘，強度乘上 `game.visualAid`。
- 每幀呼叫 `audio.setListener`。

### 8.5 假驟降（11/07 使用者選定：第 3 區起偶爾出現）【改編】

- **為什麼要有**：「驟降就是最安全的時機」容易變成死背的公式。從第 3 區（窄巷）起，大約每 4 個循環會有 1 次「無縫交接」：音樂照常交接，但沒有空檔、沒有盲區。
- **聽得出來**：假驟降之前沒有預告音；交接時最高層不會靜到全無聲，而是留著一絲極輕的金屬尾音。專心聽就不會上當。
- 不會連續兩次出現。第一次出現時，畫面下方提示：「有時鼓聲只是換手，並沒有斷：沒有那聲預告，就不要動。」
