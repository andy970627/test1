## 2. 核心玩法（交接包，加出處標記）

- **類型**：心理節奏生存／潛行【改編】
- **氛圍**：諾蘭版《奧德賽》的特洛伊段落與配樂〈Troy〉【電影】；戰爭創傷（PTSD）【改編】
- **核心**：Risset 節奏，一種聽起來無限加速的聽覺錯覺，用來驅動敵人的感知【改編】
- **機制 A：相位盲區與致命一擊**：節奏越高頻，敵人感知越強。高頻時要按住屏息、不能動。最高頻淡出、接回最低頻的約 0.5 秒是盲區，可以衝刺或暗殺
- **機制 B：恐慌共振與反向操作**：敵人起疑時音樂失控加速，玩家不能跟著加快操作，要聽底層極慢的低音，用極慢的節奏輸入安撫；輸入太快就被發現
- **狀態機**：巡邏（約 10 秒一個加速循環）→ 警戒（高頻失真，進入反向操作）→ 盲區（0.5 秒判定窗）→ 追殺（音軌全部疊加，改成逃生）
- **介面**：沒有視覺提示，靠聽覺；極端加速時刻意讓畫面和介面延遲、加雜訊，讓視聽不協調

待確認：電影特洛伊段落的具體場景（木馬、城內夜襲）要用哪一段當舞台。

## 3. 音訊引擎取捨：Web Audio vs Unity＋FMOD

| 面向 | Web Audio（網頁） | Unity＋FMOD／Wwise |
|---|---|---|
| **節拍精準度** | 用音訊時鐘 `AudioContext.currentTime` 預先排程，精度到樣本級，和 Unity 的 `dspTime` 同一個層級；**不能用畫面幀**計時（同交接包的提醒） | 最精準，FMOD 有拍點回呼與同步工具 |
| **多音軌相位、變速** | 可以：多個音源各自排程，用增益節點交叉淡入淡出；Risset 的「加速＋淡出交接」用程式合成或預錄循環都做得到 | 可以，而且有現成的參數自動化、混音器，調起來快 |
| **音質與效果** | 內建濾波、殘響（卷積）、失真、立體聲定位；夠用但要自己組 | 專業混音、殘響、側鏈壓縮、即時參數，效果最好 |
| **延遲與穩定** | 依瀏覽器與裝置：Chrome 桌機約 10～30 ms；分頁在背景時計時會被降速；第一次要玩家點一下才能出聲 | 原生程式，延遲低且穩定 |
| **畫面掉幀的影響** | 聲音在獨立的音訊執行緒，畫面卡也不會亂拍（前提是用音訊時鐘排程） | 一樣不受影響 |
| **上架與報告** | 直接放 itch.io、點開就玩，和現有網頁連作同一套 | 要建置 WebGL；FMOD 的 WebGL 支援要另外設定，檔案大、載入慢 |
| **製作速度** | 現有原型都用它，代理可以馬上做、自動測試 | 要在你電腦上開 Unity 測，我這邊沒辦法實際跑畫面與聲音 |
| **之後移植** | 規則（節奏時間表、狀態機）寫在獨立模組，可以翻成 C#；聲音的實作要用 FMOD 重做 | 本來就在 Unity；但會綁在 FMOD 上（授權、工具鏈） |

**結論**：原型階段用 Web Audio 做得出交接包要的核心體驗（精準節拍、多軌交接、低音層），代價是混音質感和裝置差異。等玩法確定、要做正式版時再換 FMOD，屆時只重做聲音層。

## 5. 交接包原文（使用者提供，11/06）

> 類型：心理節奏生存／潛行動作遊戲（Psychological Rhythm Stealth）。主題氛圍：改編自諾蘭版《The Odyssey》電影情境（特別是〈Troy〉配樂），探討戰爭創傷（PTSD）、無盡的壓迫感與極限生存。核心機制：基於聽覺錯覺 Risset Rhythm 打造的動態難度與潛行系統。
>
> 機制 A：聲納盲區與致命一擊（Phase-Shift Takedown）——環境威脅與 Risset Rhythm 綁定，頻率越高，敵人感知越強；高頻階段必須原地按住屏息鍵，任何移動都會被秒殺；最高頻淡出、無縫接回最低頻的 0.5 秒（相位重置）是聽覺暫留盲區，抓準瞬間鬆開按鍵衝刺或暗殺。
>
> 機制 B：恐慌共振與反向操作（Paranoia Resonance）——敵人起疑時音樂打破規律、失控加速；玩家不能跟著加快，必須聆聽底層極慢速重低音，以極慢頻率輸入安撫指令；被高頻帶偏而輸入過快，就被發現。
>
> AI 狀態機：巡邏（約 10 秒循環平滑加速，避開高頻峰值）、警戒（急促高頻與失真，啟動反向操作）、盲區（高頻切斷重置的 0.5 秒，開放致命一擊判定窗）、追殺（所有音軌極速疊加，轉為逃生）。
>
> 技術注意事項：使用 FMOD 或 Wwise；在 Unity 實作時三個以上音軌的相位、音高、音量必須以 `AudioSettings.dspTime` 絕對時間同步，嚴禁 `Time.deltaTime`。極端加速階段刻意讓視覺特效與 UI 延遲或加雜訊，製造視聽不協調。
