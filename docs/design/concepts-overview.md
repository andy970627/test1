## 2. 概念卡片

### A.《奧吉吉亞：第七年》異常航海
- **一句話**：在卡呂普索的島上造筏出海，一處不對勁卻沒掉頭，就被波塞頓送回沙灘，又是一年。
- **核心**：8 號出口式異常判斷；昴宿星當進度條；年數＝生命值兼故事時鐘；掛毯織出死因。
- **規模**：大（5 個里程碑）。網頁適合度 ★★★★☆，先做 M1 一個航段。
- **待決定**：巨浪倒數要不要留、掉頭操作、超過第 20 年怎麼辦、名稱、電影待確認項目（總綱第 11 節，共 5 題）。
- **原檔**：`blind-cave` 分支 `docs/design/2026-10-10-ogygia-gdd.md`

### B.《門檻上的乞丐》偽裝潛行
- **一句話**：一定會被看見，只是不能被看穿；讓求婚者瞧不起你，但別被打死，也別忍不住動手。
- **核心**：疑心／怒火／身體三方拉扯；羞辱就是掩護；視線高度＝潛行等級；乞討路線當通行證；笨拙地閃；剛好贏的拳鬥；羞辱存成復仇；**知情者**（依電影：兒子、盲眼豬倌、潘妮洛普與神像，加上洗腳的老奶媽）給優勢，但會露出破綻。
- **規模**：中到大（8 段）。最小切片只做大廳。
- **原型**：`prototypes/beggar-hall/`（宮門＋大廳，第一人稱）。規則在 `sim.js`（純邏輯、有測試，之後可翻成 C#），畫面在 `index.html`。已補潛行元素：視線遮擋、光影、警覺階段與傳染、巡邏、聲音、丟骨頭、酒罈、掌燈差事、跛行、混進僕人（設計文件 3H）。
- **待決定**：要不要做「羞辱存成復仇」、名稱。（電影待確認的項目改以【原典】保留；提早知情屬【改編】，保留）
- **原檔**：`docs/design/2026-11-01-beggar-stealth-concept.md`

### C. 伊薩卡比箭：穿過 12 把斧頭
- **一句話**：拉弓、穩住呼吸，一箭穿過排成一線的 12 個斧孔。
- **規模**：很小（一兩天）。網頁適合度 ★★★★★。
- **關聯**：乞丐的第 8 段、奧吉吉亞伊薩卡最終關都有比箭，做好可以直接當它們的結尾。
- **原型**：`prototypes/bow-contest/`（上弦＋射箭，第一人稱）。規則在 `rules.js`（純邏輯、有測試），畫面在 `index.html`。
- **原檔**：`docs/design/2026-11-01-web-game-candidates.md` 第 3 節

### D. 斯庫拉與卡律布狄斯
- **一句話**：木筏從漩渦和水下的六頭蛇影中間穿過去。
- **規模**：小。網頁適合度 ★★★★☆，2D 閃避。
- **關聯**：奧吉吉亞的特殊航段；可先單獨上架。
- **原檔**：奧吉吉亞總綱第 7 節

### E. 羊肚底下抱緊
- **一句話**：抱在羊肚下通過巨人的手。
- **規模**：小到中。定位成手機網頁小遊戲（兩隻拇指＝左右手）。
- **待決定**：要先補「讀手的方向」的判斷，否則只是狂按（主線就是因此換掉它）。舊程式可能只在你的電腦（標籤 `cave-cling-v1` 不在遠端）。
- **原檔**：`docs/superpowers/specs/2026-10-10-cyclops-cave-design.md`

### F. 海妖航段
- **一句話**：呼喚聲聽起來像你的家人，要忍住不朝聲音轉舵。
- **規模**：小。要戴耳機，手機外放打折。
- **關聯**：奧吉吉亞的特殊航段。
- **原檔**：奧吉吉亞總綱第 7 節

## 3. 兩款主力比較（決定第 1 題用）

| | 奧吉吉亞 | 乞丐 |
|---|---|---|
| 類型 | 觀察、找異常 | 演戲式潛行 |
| 和主線的差異 | 大：明亮的海、看與判斷 | 中：一樣是「不能暴露」，但在光下、人群裡 |
| 設計完成度 | 高（總綱、里程碑、異常池都有） | 中（機制與關卡有了，數值沒有） |
| 最大風險 | 異常太難或太簡單；海面畫面吃效能 | 三個狀態太複雜；NPC 行為工作量大 |
| 最小可玩版本 | 一個航段＋6 個異常 | 大廳＋10 名求婚者 |

## 4. 引擎與平台路線（摘要）

| 之後改什麼 | 浪費程度 | 說明 |
|---|---|---|
| 只換平台（Unity 網頁 → 電腦 → 手機） | 很低 | 同一個專案輸出；手機要重做觸控操作 |
| 換架構 | 低到中 | 規則放在純 C# 核心（`Odyssey.Core` 的做法）就不受影響 |
| 換視角 | 中到高 | 關卡、鏡頭、操作、手感都要重來 |
| 換引擎 | 高 | 只留得下文件、數值、文字；規則要翻成另一種語言 |

省 token 的原則：動工前先定視角；拋棄式原型要說好是丟的；規則和畫面分開；長規格配一份短的目前狀態摘要。

## 5. 融合搭配（2026-11-05）

詳見 `docs/design/2026-11-05-fusion-analysis.md`。
- 各遊戲依《奧德賽》時間線不重疊：洞穴（第 9 卷）→ 奧吉吉亞（第 5 卷）→ 乞丐（第 17～20 卷）→ 比箭（第 21 卷）。
- 共同主題：宙斯的待客法則、名字（喊出 vs 藏起）、薛西弗斯式的徒勞；四款各用一種感官（聽、看、被看、看準）。
- 建議做成「連作」：各章單獨可玩，加上可選的跨章存檔。順序：主線 → 乞丐＋比箭 → 奧吉吉亞。
- `odyssey-horror` 分支是《奧吉吉亞》的早期版本（另一個 Unity 2022.3 專案，有手電筒等違反內容規則的地方），建議併入 B1。
- 待決定：融合形式、B1/B2 合併、總結局基調。（內容規則已定：電影為主、原典補充、可適度改編）
