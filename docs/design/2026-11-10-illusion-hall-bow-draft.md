### 1.2 新玩法步驟（比箭）

1. **第一步：持弓上弦（蓄勢）**
   - 玩家按住滑鼠左鍵拉弦，畫面特寫奧德修斯青筋暴起的手臂與神弓硬木。
   - 伴隨拉弦，謝帕德音階持續無盡向上爬升（200～4000 Hz），音高永遠在拉高；玩家藉由微調滑鼠水平維持張力指針在中央安全區。
   - 成功拉滿後進入「瞄準射擊」階段。
2. **第二步：凝神拉弓（聽覺壓迫推進）**
   - 視角切換至第一人稱，準心對準遠方排成一直線的十二把戰斧青銅孔眼。
   - 背景響起沉重的四層 Risset 心跳聲（低音重踏、胸腔共鳴、脈搏跳動、金屬震顫），速度開始不斷飆升。
   - 求婚者的嘲弄謾罵聲隨著心跳加速越來越囂張；準心隨實際速度逐漸擴大晃動範圍。
3. **第三步：捕捉放箭時機（三種選擇）**
   - 玩家不需要等待音樂停頓，而是專注聆聽節奏層的演變：
     - **選擇 A：重合擊掩護箭（最優解）**：當四層心跳加速至交接點時，每一層的第一拍剛好重合，耳中傳來一聲震徹胸膛的「最強心跳重擊」，大廳光影在瞬間發生微震，進入 0.5 秒的專注餘韻窗。此時鬆開左鍵，箭矢在極致穩定的準心（`amp` 0.0005 弧度）下一發穿心。
     - **選擇 B：踩拍放箭（次優解）**：若錯過重合擊，不必死等下一個循環。玩家可在心跳的骨幹拍點（拍點 $\pm 0.08$ 秒內）放箭；心跳敲擊聲蓋過手臂顫抖，準心晃動適中（`amp` 0.0025 弧度），仍有極高機率穿孔。
     - **選擇 C：拍間亂射（失誤）**：在心跳拍點之間慌亂鬆手，手臂正處於心跳衝擊的劇烈晃動中（`amp` 0.0095 弧度），箭矢極易偏斜擦碰斧環。
4. **第四步：穿環貫穿（結算釋放）**
   - 箭矢脫弦而出，鏡頭進入超慢動作微距跟隨，每穿透一把戰斧的青銅孔，青銅共鳴便奏出「回家的動機」下一個音符；連穿十二孔後轟然釘入大廳終點門柱，求婚者全場震驚失色，無縫切入終章大廳復仇。

  - `Coincident Hit`：重合擊觸發倒數計時與當前突出量（dB）。
  - `Cover Window Remaining`：掩護窗剩餘秒數（0.500 秒遞減至 0.000 秒，綠字）。
  - `Current Spread (amp)`：即時準心晃動半徑（弧度）。
  - `Last Input Offset (off)`：上次放箭時間相對於重合擊或拍點的偏差毫秒數（ms）。
  - `Shot Result`：`COVER_PERFECT` / `TAP_HIT` / `OFF_MISS`。
- **常數即時調整滑桿**：
  - `BOW_COVER_LEN`（0.30～0.80 秒，步進 0.05）。
  - `BOW_LEAD_GRACE`（0.05～0.20 秒，步進 0.01）。
  - `BOW_SPREAD_TAP`（0.001～0.005 弧度）。
  - `BOW_COINCIDENT_BOOST_DB`（6～20 dB）。
- **可程式量化驗收數字**：
  - **驗收項 B1（模擬高斯玩家成功率）**：以標準差 $\sigma = 0.12$ 秒的程式模擬玩家（按鍵時間呈常態分布的高斯隨機偏差），在掩護窗（0.5 秒＋0.12 秒前沿寬限）下的放箭成功率必須 $\ge 85\%$。
  - **驗收項 B2（重擊音量突出量）**：錄音分析工具量測交接處 300～1200 Hz 頻段，重合擊峰值 RMS 比交接前 1 秒平均音量突出 $\ge +14\text{ dB}$。
  - **驗收項 B3（殘響尾巴長度）**：重合擊後殘響落回環境音 $+3\text{ dB}$ 以內的時間，中位數必須精確落在 $0.45\sim 0.55$ 秒內，不得超時溢出掩護窗。
  - **驗收項 B4（亂放懲罰度）**：在拍間（離拍點 $> 0.12$ 秒）盲目放箭的穿孔成功率必須 $\le 15\%$。

### 2.2 新玩法步驟（大廳復仇）

#### 前半：射箭段（The Archery Stage）
1. **開局蓄勢與首發放箭（第 0～1 輪）**：
   - 奧德修斯立於大廳門檻，左下忒勒馬科斯、右下老牧豬人手持長矛敲擊青銅盾沿，發出清脆的 2.8～4 kHz 規律拍點（`STRIKE_LAYER` 揮砍拍）。
   - 背景戰鼓加速奔馳。玩家可踩在盾沿拍點上放箭（踩拍箭），弓弦聲被盾沿清脆的金屬撞擊完全遮蓋，射殺逼近的普通求婚者。
2. **面對桌板頭目（第 2～3 輪）**：
   - 四名頭目手持厚木桌板逼近，普通踩拍射頭或胸會被桌板擋下（`leader_guarded`）。
   - 玩家策略分流：
     - **戰術 A（下盤破綻）**：在揮砍拍上射擊頭目下盤，頭目腿部中箭痛跪、桌板脫手（`kneel` 破綻）；隨即在下一個拍點放箭射胸處決。
     - **戰術 B（重擊掩護箭）**：聆聽戰鼓加速至極致，在戰意重合擊轟然落下（塵土震落、火把微歪）的 0.6 秒掩護窗內放箭，弓弦聲被天地轟鳴吞沒，箭矢精準穿透破綻。
3. **防禦與號令協同**：
   - 敵方在命中拍投擲長矛或飛撲逼近：玩家可點右鍵以弓身撥開（招架），使敵方踉蹌泛白光，並在反擊窗內回敬必中反擊箭；或在低音拍（2.4 秒）按 1 號令兒子舉盾硬擋。
   - 箭矢不足時，在低音拍按 2 號令兒子取箭（`fetch`）。

#### 轉折：衝鋒（The Charge Transition）
- 當倒下頭目達到 2 名時，該輪結尾無縫進入 1 個循環的 `charge` 轉折（無攻擊）。
- 鼓聲不中斷，老僕喊出「他們拔劍了！」，兒子遞上重矛與青銅圓盾，字卡浮現「他們拔劍了。拿起矛。」，戰鬥無縫進入近戰段。

#### 後半：近戰段（The Melee Stage）
1. **暖身進攻（近戰第 1～3 輪，一輪教一事）**：
   - **第 1 輪**：雜兵只守不攻，玩家學習手持長矛踩著盾沿敲擊拍點揮砍（對拍戳刺命中，錯拍被架住但不進 OPEN）。
   - **第 2 輪**：雜兵發動攻擊，學習在命中拍點右鍵招架（觸發白光硬直），並在反擊拍揮矛處決。
   - **第 3 輪**：揮砍與招架混合演練。
2. **全面混戰與破防推擊（近戰第 4 輪起）**：
   - 攻位（3 個近戰站位）由頭目接管，頭目全程橫劍護身，常規對拍砍會被招架彈開。
   - **核心殺招（震波借力推擊）**：當循環加速到交接點、戰意重合擊轟鳴與大廳塵土落下的 0.6 秒掩護窗內，左鍵點擊目標發動「震波推擊」——奧德修斯藉震波之勢盾擊猛推，頭目直接受創 1 點破綻傷害並倒飛 2.5 公尺！若將其推入中央火盆，衣角燃燒再額外扣 1 點血！
   - **團隊破防號令**：在低音拍按 2，老牧豬人衝出夾擊側翼頭目（使其無法招架、泛白光破綻）；按 3 號令牧牛人頂住側門，阻斷後方敵人補位。
3. **終極決戰（最後一名頭目）**：
   - 剩最後一名頭目時，循環縮短至 2 拍 4.8 秒極限高壓，揮砍拍自動切換至第 0 層（拍距拉寬至 0.56 秒以上防止亂按狂點）。
   - 玩家靈活運用側移走位、招架反擊與火盆推擊，徹底擊潰最後的求婚者頭領，其餘雜兵丟盔棄甲跪地投降，迎來大廳復仇的壯烈破曉。

  - `COVER_LEN`（0.40～0.80 秒，步進 0.05）。
  - `COVER_LEAD_GRACE`（0.05～0.25 秒，步進 0.01）。

  - `SHOVE_DIST`（1.5～3.5 公尺）。
  - `COVER_COINCIDENT_BOOST_DB`（6～20 dB）。
- **可程式量化驗收數字**：
  - **驗收項 H1（射箭掩護成功率）**：高斯模擬玩家（$\sigma = 0.12$ 秒）在掩護窗（0.6 秒＋0.15 秒寬限）內放箭，掩護認定成功率必須 $\ge 88\%$。

  - **驗收項 H3（推擊連鎖有效性）**：在近戰掩護窗發動推擊，前方 2.5 公尺內目標擊飛位移誤差 $\le 5\%$，火盆與翻桌碰撞判定率 100%。

  - **驗收項 H5（無縫換層密度驗收）**：最後一名頭目縮短至 4.8 秒並切換至第 0 層時，拍距最小間距必須 $\ge 0.56$ 秒，且整體 Risset 音量包絡（RMS）起伏 $\le 0.5\text{ dB}$，證明換層無接縫。

## 3. 和木馬之夜甲版的一致處

本設計嚴格遵循「同一套心智模型在三個章節通用，教一次就適用全局」的通用性原則：

```
                    【奧德賽全局統一的聽覺法則】
        ┌──────────────────────────────────────────────┐
        │ 1. 鼓聲永不斷：Risset 錯覺是世界底層法則，永遠奔馳。  │
        │ 2. 趁最響的動：交接處「重合擊與殘響」是最大掩護窗。   │
        │ 3. 踩著拍點走：平時行動踩在聽得到的拍上，聲響被遮蓋。 │
        │ 4. 眼睛不被騙：耳朵可以靠鼓聲掩護，視野內動必被盯上。 │
        │ 5. 慢低音是指南：混亂中聽不動的慢拍（2.4s），下令回氣。│
        └──────────────────────────────────────────────┘
```

| 核心規則 | 木馬之夜甲版（序章） | 比箭 Risset 版（中章） | 大廳復仇 v2 維持錯覺版（終章） | 跨章節通用機制與心智模型 |

## 4. 風險與未決事項（列給設計席裁決）

本節針對維持錯覺改版中面臨的 4 大核心衝突，整理出具體決策選項與設計席建議：

### 議題 1：比箭中「最強心跳重擊」在筆電喇叭上的可辨度問題
- **問題描述**：比箭原本用「突然安靜」來提示放箭，即使百元耳機或筆電破喇叭也能聽出「沒聲音了」；改為「心跳重合擊」後，純低頻脈搏（$<150\text{ Hz}$）在筆電喇叭上會完全消失，玩家可能聽不出「那一聲是最響的」。
- **選項**：
  - **選項 A（中頻胸腔共振疊加，建議）**：在重合擊當下，除了底層重低音，強制疊加一軌 350～850 Hz 的「深層胸腔吸氣與皮甲繃緊聲」，並在此刻將求婚者的高頻嘲弄施加 0.5 秒的低通濾波（把尖銳聲音削掉，製造耳朵暫時發悶的生理壓迫感）。實測可保證筆電喇叭突出 $\ge +14\text{ dB}$。
  - **選項 B（保留視覺強提示）**：準心在重合擊瞬間強烈收束為純金色亮點，完全依賴視覺。
  - **選項 C（加入骨傳導耳鳴高頻）**：在重合擊瞬間發出一聲 3.5 kHz 的極短促蜂鳴。
- **設計席建議**：**採選項 A**。選項 B 違背了「聽覺切入」本意，選項 C 聲音過於刺耳像現代閃光彈，破壞荷馬史詩古希臘質樸感。選項 A 兼具心理沉浸與喇叭物理可聽性。

---

### 議題 2：大廳復仇「震波推擊」與「招架反擊」是否會產生空檔重疊搶鍵？
- **問題描述**：若玩家在交接前最後一拍剛好招架了敵人的進攻，敵人在反擊窗內泛白光；緊接著進入 0.6 秒掩護窗，此時玩家點擊滑鼠左鍵，系統究竟該結算為「近戰反擊刺殺（必中 2 點）」還是「震波推擊（飛退 2.5 公尺）」？
- **選項**：
  - **選項 A（二擇一智能覆蓋：推擊優先，反擊順延，建議）**：掩護窗 0.6 秒內左鍵恆定為「震波推擊」。若目標剛好是泛白光的被招架者，推擊直接吃滿「推擊 1 點＋反擊 2 點＝直接暴擊 3 點」，目標被轟飛；若玩家想留著長矛戳刺，反擊窗順延至掩護窗結束後的第一個揮砍拍。
  - **選項 B（按鍵分離）**：將推擊改為滑鼠滾輪或鍵盤 E 鍵，左鍵保留給長矛刺擊。
  - **選項 C（嚴格反擊優先）**：只要有人泛白光，左鍵一律結算為長矛刺擊，推擊被吃掉。
- **設計席建議**：**採選項 A**。大廳復仇的滑鼠操作極致精簡（左鍵打、右鍵防），增加按鍵會造成手忙腳亂（違反規則 3）；選項 A 讓玩家的成功招架與抓準重擊形成「雙重獎勵大暴擊」，手感最為爽快解恨。

---

### 議題 3：大廳復仇中預告音（空心木塊敲擊）在不中斷模式下是否該完全移除？
- **問題描述**：木馬之夜甲版將預告音降為教學輔助並隨 `visualAid` 淡出；在大廳復仇中，戰意重合擊前 0.4 秒的「叩、叩」兩聲空心木塊，會不會讓玩家又變回「聽預告音條件反射」，而忽略了戰鼓整體的加速韻律？
- **選項**：
  - **選項 A（教學淡出制：第 0～2 輪保留，之後歸零，建議）**：比照木馬之夜，前 2 輪暖身時保留空心木塊（落在揮砍拍中點），讓玩家建立「快要到大重擊了」的時間感知；第 3 輪起木塊聲歸零，僅保留掩護窗前 0.3 秒音樂自然變亮 4 dB（`COVER_BRIGHT_DB`）。
  - **選項 B（全程保留）**：將空心木塊合理化為「老僕歐邁俄斯敲擊矛桿提醒」，全程存在。
  - **選項 C（開局即徹底刪除）**：完全不給木塊預告，完全靠耳朵抓戰意重合擊。
- **設計席建議**：**採選項 A**。大廳復仇進入戰鬥後認知負荷高於潛行，開局直接無預告容易導致前兩輪推擊率過低引發挫折；選項 A 的動態退場最符合技能學習曲線。

### 議題 4：比箭是否需要引入「無重擊的假交接（原假驟降）」作為陷阱？
- **問題描述**：在舊版總綱規則 9 中，曾規劃「比箭第 3 輪起約每 4 輪出現 1 次假驟降，打破死背」。現在改為維持錯覺後，是否要設計「沒有重合擊的交接」來懲罰死記秒數的玩家？
- **選項**：
  - **選項 A（第一批不引進，暫緩至報告後，建議）**：比箭是單一焦點的專注體驗（一局僅 20～40 秒），核心在於「極限壓迫下心神合一射出一箭」，而不是抓抓內鬼或陷阱；維持純粹的無縫加速，不增加假交接。
  - **選項 B（引入「虛弱脈搏」陷阱）**：第 3 輪起隨機出現一次心跳未重疊，該交接點心跳極微弱且準心發散，在此放箭直接脫靶。
- **設計席建議**：**採選項 A**。比箭的遊玩時長極短，容錯率低，加陷阱只會帶來無謂的煩躁感；保持流暢痛快的釋放才是高潮定位。

## 6. 專有詞彙速查與白話對照

依據專案規範，所有專有名詞在文件中首次出現時均需附帶括號白話定義，本節集中收錄關鍵詞彙供查閱：

1. **Risset 節奏（Risset rhythm）**：一種聽覺錯覺；好幾層速度成倍數的鼓點各自加速，最快的淡出、最慢的淡入，耳朵聽起來節奏永遠在無止境飆快，卻永遠回不到起點。
2. **謝帕德音階（Shepard scale）**：音高版本的無盡錯覺；好幾個八度的音階一同向上滑動，最高的淡出、最低的淡入，聽起來音調永遠在升高，永遠沒有極限。
3. **掩護窗（cover window）**：循環交接時各層第一拍同時落下的最強一擊，加上隨後 0.5～0.6 秒的餘韻殘響；這段時間敵人感知歸零或視聽被壓制，是玩家發動大招、射箭或推擊的最佳時機。
4. **重合擊（coincident hit）**：Risset 循環交接瞬間，每一層加速鼓點剛好同時敲在同一個時間點上，疊加成全曲能量最高、最厚實的一記重擊。
5. **遮蓋（masking）**：聲學心理學效應；當一個較大聲或頻段寬廣的聲音響起時，人類耳朵會完全聽不見同時間發生的另一個微弱聲音（如鼓聲遮蓋腳步、盾沿金屬聲遮蓋弓弦震顫）。
6. **殘響（reverb）**：聲音停止發聲後，在房間或大廳空間內反射迴盪的餘韻。
7. **拍點（beat point）**：由遊戲規則層數學公式嚴格計算出的某一拍該發聲的時間點；遊戲中所有聲音、畫面與按鍵判定都唯一參照此時間點。
8. **相位 p（phase）**：目前節奏循環推進的百分比進度（0.0 代表剛開始，接近 1.0 代表快到最緊繃的極限，跳回 0 代表進入下一輪循環）。
9. **循環 T（cycle）**：節奏相位從 0 走到 1 的總秒數；數值越短代表鼓聲催促得越急迫。
10. **細分拍（subdivisions）**：把一個大拍切得更碎的細密拍子（如一拍切成 4 個小敲擊）。
11. **判定窗（timing window）**：玩家按下按鍵被系統算作「正確成功」的有效時間區間（單位為秒，如 $\pm 0.14$ 秒）。
12. **不對稱窗（asymmetric window）**：判定窗在標準拍點前後的寬度不相等（通常晚按側給得較寬，用來補償人類神經反應與耳機輸出延遲）。
13. **高斯玩家（Gaussian player）**：測試程式中模擬真人的自動化腳本；每次按鍵時間為目標拍點加上一個標準差 $\sigma$（如 0.12 秒）的常態隨機誤差。
14. **攻位（slot）**：近戰時環繞在玩家前方 2.0 公尺圓弧上的 3 個固定敵人站位（$-40^\circ$、0、$+40^\circ$），一個位置站一名攻擊者，其餘敵人在外圍排隊。
15. **破綻（opening）**：持桌板或架劍防禦的頭目露出破綻的狀態（如被招架硬直、射腿跪地、被僕人夾擊或被推擊擊飛）；此時全身發白光，受攻擊才會扣減生命值。
16. **越危險越快（danger scaling）**：隨著關卡危險度提升（如敵人逼近、剩餘頭目減少），背景節奏循環自動平滑縮短、逼迫玩家加快決策的調節機制。
17. **呈現覆蓋率（presentation coverage）**：所有被程式拿來判定的拍點中，在 $\pm 30$ 毫秒內有明確畫面或聲音反饋的比例（專案總綱要求 100%）。
18. **音訊時鐘（audio clock）**：瀏覽器音訊系統（Web Audio）內部的高精度獨立計時器，精度達毫秒級，完全不受畫面掉幀影響。
