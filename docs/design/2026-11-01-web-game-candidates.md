## 3. 建議

1. **先做 #1 比箭**：一兩天的量，最快有可以分享的網頁成品，也能測 itch.io 的上架流程。玩法：拉弓力道＋準心晃動（呼吸），12 把斧頭的孔要排成一線才能穿過；失敗就看見追求者在笑。
2. **再做 #2 奧吉吉亞的 M1 垂直切片**（一個航段、6 個異常、巨浪、失敗畫面）：最有機會變成獨立作品。網頁版可以先用固定鏡頭的低多邊形海景，不做完整海面著色器，降低 WebGL 負擔。
3. **#3 斯庫拉與卡律布狄斯**可以當 #2 的特殊航段，也可以先單獨上架當小品。
4. **#4 羊肚底下**若要做，定位成手機網頁小遊戲，並先改掉「只要手夠勤快就過」的問題。

技術面：主線已經有 Unity WebGL 建置與 itch.io 上傳流程（`ci-webgl-itch` 分支、`docs/ci-setup.md`），#2、#4 可以直接沿用 Unity；#1、#3 是 2D 小品，用 Unity 也行，改用純網頁（Canvas）載入會更快、手機更順。

## 4. 待你決定

- 先做哪一個（建議 #1 → #2）。
- 2D 小品要用 Unity WebGL（共用程式與流程）還是純網頁（載入快、檔案小）。
- 獨眼巨人洞穴規格裡提到的標籤 `cave-cling-v1` 不在遠端，#4 的舊程式可能只在你本機。
