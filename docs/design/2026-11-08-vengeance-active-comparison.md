# 《大廳復仇》主動性：方向 A、B 比較與建議組合

日期：2026-11-08　起因：使用者「終章被動的比例太大」。
依據：`2026-11-08-vengeance-active-archery.md`（A 節奏射箭自由度）、`2026-11-08-vengeance-active-melee.md`（B 近戰比例加大）、`2026-11-08-music-core-concept.md`（核心總綱，13 條搭配規則）、`2026-11-08-music-gameplay-beyond-odyssey.md`（搭配點診斷：大廳復仇 6/10，病因是「節奏是音樂給的、不是玩家做出來的」）。

## 1. 結論

**建議「A 前半＋B 後半」合成一款，照原典順序：先射箭、箭盡或倒下兩名頭目後衝鋒換矛劍。** 兩份規格的作者各自寫的接口已經對得上：同一條拍線（Risset 第 1 層當可踩拍）、同一個空檔意義（必中、一次、大招）、同一套低音拍號令、氣條從第 0 循環就在。先實作的是最小可玩組合（下面第 4 節），不是兩份規格的全部。

每循環的主動選擇：現況 1 個決定＋2 個反應 → A 至少 4 個 → B 7 個 → 合成版前半 4、後半 5～6。

## 4. 建議的最小可玩組合（第一批）

前半（射箭段，沿用現有加 A 的核心）：
1. 踩拍箭／亂射二分（`STRIKE_LAYER` 可踩拍、窗 ±0.06／+0.04；亂射偏差 ±0.2 並暴露）。
2. 部位：頭／胸／下盤（跪下、桌板掉、取消這輪出手）。
3. 低音拍號令輪只先做兩格：舉盾、取箭。
4. 氣條從第 0 循環就在（閃避 −1、低音拍對拍 +1）。
5. 逐步解鎖：第 0～3 輪只有盾。

轉折：倒下 2 名頭目（殘酷 1 名）就衝鋒，不論箭數；1 個無攻擊循環，兒子遞矛與盾。

後半（近戰段，B 的核心）：
6. 揮砍拍＝同一條 `STRIKE_LAYER`，盟友敲盾沿呈現；三個攻位用準心選。
7. 招架（命中拍 ±0.14 點右鍵）→ 下一揮砍拍反擊必中；硬擋（按住）耗氣。
8. 空檔推擊（火盆、桌板、人群）。
9. 牧豬人、牧牛人各一個號令格（上前夾擊、守門）。

第二批（驗證過第一批再做）：A 的蓄力穿透與喝令、B 的擲矛與劍、羊倌偷武器事件、頭目性格、假驟降。

**驗收**（取兩份規格的交集，對應總綱 N1～N3）：主動時間比例 ≥ 50%；每循環選擇數中位 ≥ 2；程式玩家主動策略比保守策略勝率高 ≥ 20 個百分點、用時快 ≥ 30%；一般熟練度（σ 0.12 秒、40% 漏按）勝率 ≥ 55%。

## 5. 要先解決的衝突

1. **滑鼠左鍵**：A 要「按住拉弓、放開射」，B 要「點一下揮砍」。合成版：射箭段按住拉弓、近戰段點擊揮砍，以 `game.phase` 切換；轉折循環有一次提示。
2. **右鍵**：射箭段舉盾、近戰段招架。兩者都是「擋住當下那一下」，差在代價；若本機試玩混淆，改成右鍵全程招架、舉盾放中鍵或數字鍵。
3. **滾輪**：A 的號令輪用滾輪選；B 建議近戰段號令退到數字鍵 1／2／3。合成版兩段都用數字鍵選號令、右鍵執行，滾輪不用（和「同時按鍵不打架」一致）。
4. **轉折觸發**：不能靠箭盡（A 讓箭變多、取箭會補箭），改「倒下 2 名頭目」。
5. **呈現統一**：拍線的畫面元素從第 0 循環就是盟友敲盾沿；火焰隨拍跳保留當環境，不當判定依據。

## 6. 待使用者決定（選擇題）

1. 方向：合成版（建議）／只做 A／只做 B／維持現況只修喇叭可聽度。
2. 第一批要不要含近戰段（建議含，否則「終章被動」只解一半）。
3. 近戰段預設開不開「越危險越快」（B 建議開；但 2 拍 4.8 秒對揮砍動畫擠，建議近戰段下限 3 拍）。
4. 11/12 報告：大廳復仇 15 秒用現版（建議，規格先寫好當「下一步」講）／趕第一批。
