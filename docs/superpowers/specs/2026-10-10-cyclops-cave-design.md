# 獨眼巨人的洞穴 — 羊肚底下的潛行（設計規格）

日期：2026-10-10
專案：`C:\Users\恩\test1`（Unity 6000.3 LTS、URP Forward+、只用 Input System）

## 1. 目標與限制

**目標**：做出可實測的雛形，驗證「抱在羊肚底下撐過洞口」這個核心玩法夠不夠緊張、好不好玩，實測後再發想細節。

**限制**
- 所有場景、道具、音效、文字都必須出自《奧德賽》，不得出現現代或真實世界場景。
- 不做異常判斷玩法（舊的 Exit 8 式迴廊整個拆掉）。
- 第一人稱。
- 無美術資源：幾何用程式產生的佔位物件，音效用程式合成。
- 恐怖感來源是「看不見、只能聽」與「努力不累積」，不是突然跳出來的驚嚇（Jump Scare）。

**成功標準**
- 從 Unity 選單一鍵建好場景、按 Play 即可玩完整一輪。
- 第一次玩大概率失敗，第三次左右有機會成功（可在 Inspector 調整）。
- 每輪結果寫進 CSV，可事後分析失敗原因。

## 2. 整體流程與失敗循環

一輪：

1. **開場**：黑畫面顯示「第 N 夜・剩下 X 名同伴」（重用 `LoopFailScreen`）。
2. **洞底選羊**：巨人（已被刺瞎）堵在洞口，羊群一隻隻出洞；玩家須在羊走光前鑽到某隻羊肚下。
3. **洞口抱緊**：所抱的羊排隊走向洞口，巨人摸每隻經過的羊，玩家以握力、呼吸、重心撐過。
4. **結果**
   - 羊走進月光、離巨人數公尺 → 逃出成功（結局）。
   - 被手摸到／握力耗盡摔下／憋氣到極限喘出聲 → 被抓：黑畫面、吃掉一名同伴，回到洞底重來。
   - 羊全部走光仍未抱上任何一隻 → 同樣算被抓。

跨輪：
- **歸零**：玩家位置、羊群出洞順序（每輪隨機打亂；大公羊固定最後）。
- **保留**：同伴人數，從 12 遞減；洞底角落顯示剩下的同伴（佔位人形）。
- **結局**
  - 成功：「你逃出去了。」→「但你對著巨人喊出了自己的名字。」（波賽頓詛咒的伏筆）
  - 同伴歸零：「洞裡只剩下你。」遊戲結束，可重新開始。

一輪預估 1～2 分鐘。

## 3. 第一段：洞底選羊

**場景**
- 不規則天然岩洞，約 30×20 公尺；起伏地面、凹凸洞壁、高而黑的洞頂，沒有直線與平面。
- 中央一堆將熄的炭火（主光源，紅橙、晃動）。
- 火邊斜靠尖端燒焦的橄欖木樁。
- 牆邊乳酪架與奶桶；角落縮著剩下的同伴。
- 洞口在一端，透進微弱藍色月光；巨人坐在洞口，背光呈巨大黑色剪影。

**羊群**
- 每輪 8～10 隻，緩慢遊走並咩叫。
- 每隔數秒，排在洞口最前的羊出洞；約 60～90 秒全部走光（時間壓力）。
- 普通羊：體型小、握力消耗快，巨人摸得快。
- 大公羊（一隻）：固定最後出洞；毛厚、握力消耗慢，但巨人摸得久（2～3 輪）並對牠說話。

**玩家**
- 永遠蹲姿、慢速移動的第一人稱。
- 對準一隻羊按住 E 約 1 秒 → 鑽進羊肚下，進入第二段；若該羊已在排隊，便隨隊伍前進。

**巨人的聽覺**
- 玩家移動會產生聲量；靠近洞口、撞到奶桶時聲量較大。
- 羊叫聲可遮蔽玩家聲量（附近有羊在叫時，玩家聲量打折）。
- 聲量超過門檻 → 巨人的手往聲源方向在地面掃過；被手碰到即被抓。

**刻意不做**：撿道具、搬物品、與同伴互動。

## 4. 第二段：洞口抱緊

**畫面**：仰躺在羊肚下，視線大半被羊毛遮住，只能從羊腿縫隙看到移動的地面與漸近的月光；羊每走一步畫面顛一下。

**三條身體狀態**（不顯示數字，只用身體回饋）

| 狀態 | 操作 | 消耗／恢復 | 失敗 | 回饋 |
|---|---|---|---|---|
| 握力 | 按住滑鼠左鍵＝左手、右鍵＝右手 | 抓著消耗、放開恢復；兩手皆放開時身體下滑 | 滑到底摔下 | 手指發抖音效；畫面下沉 |
| 呼吸 | 按住空白鍵憋氣 | 憋氣累積缺氧；放開大口換氣（發出聲音） | 缺氧到極限，不受控喘出聲 | 心跳聲變大、畫面邊緣變暗 |
| 重心 | A/D 貼向左／右 | 不消耗；切換時發出羊毛摩擦聲 | 被手摸到所貼的那一側 | 畫面向所貼側傾斜 |

**巨人的手**
- 每隻經過洞口的羊固定流程：先摸背（須憋氣）→ 再從某一側摸下到羊肚（須貼另一側）。
- 大公羊會被摸 2～3 輪並伴隨巨人說話。
- 手的方向預兆：左右聲道的呼吸與摩擦聲、頭頂羊毛被壓下的凹陷位置、該側畫面輕微震動。
- 兩難：換手抓會短暫鬆手（恢復握力但下滑）；手靠近時換氣或換邊會被聽到或碰到。

**通過**：約 15～25 秒（視前方排隊羊數與是否為大公羊）；羊走進月光、離巨人數公尺即成功。

**難度**：所有數值暴露在 Inspector，預設調到首玩多半失敗、約第三次可成功。

## 5. 程式架構

**移除**：`CorridorSegment`、`Anomaly`、`Pursuer`、`OdysseyPlaytest`、舊實測場景 `Assets/Scenes/OdysseyPlaytest.unity`。

**保留並調整**
- `FirstPersonPlayer`：改為固定蹲姿、慢速，並對外回報移動聲量。
- `LoopFailScreen`：開場、被抓、結局的黑畫面文字。
- `OdysseyFonts`、`OdysseyMaterials`：中文字型、佔位材質。
- `ProceduralAudio`：保留巨人低吼；刪除里拉琴、海浪；新增羊叫、心跳、羊毛摩擦、巨人呼吸。
- 編輯器選單 `Odyssey/Create Playtest Scene`：改為建立洞穴場景。

**新元件**

| 元件 | 職責 |
|---|---|
| `CaveBuilder` | 程式產生不規則岩洞（地面、洞壁、炭火、木樁、乳酪架、奶桶、洞口月光）與碰撞 |
| `Sheep` | 單隻羊：遊走、排隊、被摸時停下、可承載玩家 |
| `SheepFlock` | 生成羊群、決定出洞順序（大公羊最後）、出洞倒數 |
| `Cyclops` | 洞口巨人剪影：依聲量往地面掃手；對每隻經過的羊執行摸背→摸側流程 |
| `NoiseListener` | 彙整玩家聲量（移動、碰撞、喘氣、換邊），供巨人判斷 |
| `ClingController` | 第二段三條身體狀態、羊肚下鏡頭與畫面回饋 |
| `CrewRoster` | 同伴人數（起始 12）與洞角落的同伴顯示 |
| `CaveGameLoop` | 狀態機：開場 → 選羊 → 抱緊 → 逃出／被抓 → 下一輪 |

依賴方向：`CaveGameLoop` 協調其他元件；`Cyclops` 只依賴 `NoiseListener` 與 `Sheep`；`ClingController` 只依賴目前所抱的 `Sheep` 與 `Cyclops` 發出的摸羊事件。

## 6. 實測與驗證

- **建置驗證**：每次交付前以 dotnet 對專案參考組件完整編譯（執行期 runtime 與編輯器 editor 兩個組件），零錯誤才交付。
- **實測流程**：選單 `Odyssey → Create Playtest Scene` → Play。
- **F1 除錯面板**：握力、呼吸、聲量的實際數值；巨人下一次摸哪一側；目前狀態機階段。
- **CSV 紀錄**（`Application.persistentDataPath/cyclops_playtest.csv`）：每輪的夜數、剩餘同伴、所選羊（普通／大公羊）、結束階段、結果（逃出／被手摸到／摔下／喘出聲／羊走光／選羊時被掃到）、耗時秒數。
