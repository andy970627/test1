**為什麼這樣排**：主線最成熟、最不需要背景知識，適合當主角；比箭最直觀，適合放在影片結尾；乞丐和連作的強項是「AI 分工」的故事，所以放在 AI 分工那段講，不必塞進影片。

## 3. 給錄影的備註

- 主線洞穴要在你電腦上用 Unity 錄（網頁版沒建置）。`blind-cave` 分支有專案自己的試玩檢查技能（skill，`.claude/skills/verify-odyssey/`），可以先跑一次確認每個功能正常再錄。
- 主線畫面很暗，錄影前調高螢幕或遊戲亮度，或後製提亮。
- 乞丐要錄站直的片段，畫面才看得到求婚者和「？／！」。
- 冥府沒有聲音就看不懂，放進影片的話要開聲音。
