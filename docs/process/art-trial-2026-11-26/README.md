## 介面風格統一試做（美術 C，11/27）：`ui/` 資料夾

開法：網址加 `ui=2`，例如 `troy-prologue/index.html?map=final&ui=2`，可和 `art=2` 一起開。不加參數時畫面和以前一樣。

- 範圍：標題畫面、按鍵鍵帽與提示、對話框與字卡（含序、終）、抬頭顯示（區名、提示、訊息、屏息條）。只改樣式，不改任何文字與判定；提示內容和原本一字不差。
- 風格：暗色寫實，火把橘當重點色（標題下的短火線、分區標題、主要按鈕、鍵帽底邊、提示框上緣）；全螢幕畫面下緣一層火光暖暈；提示墊深色底，3D 再亮也讀得到。
- 字體：內文思源黑 500（鍵帽、按鈕 700）；故事句（開場三段敘事、序與終字卡、成功與失敗那一句、耳語）用霞鶩文楷。文楷從 Google Fonts 載，沒網路時退回系統楷書（標楷體）；思源黑沒網路時用本機的 Noto Sans TC，再退回微軟正黑體。
- 截圖（每組 ui0＝原本、ui2＝試做）：`1-標題`、`2-腹中練習`、`3-關口提示-城門門閂`、`4-序字卡`。
- 幀數（1280×720，城門門閂前凍結畫面，各量 3 次）：RTX 3060 不鎖幀數 ui0 361～391、ui2 325～364（約少 8%，都遠高於螢幕的 60 幀）；軟體算圖（模擬沒有顯示卡）ui0 25～33、ui2 31～35，差距在誤差內。
- 已知：霞鶩文楷 TC 把「為」畫成「爲」字形（字型本身的寫法，文字沒變）。
