# 製作紀錄（和遊戲內容無關的文件）

這個資料夾放「怎麼做出來的」，不放「遊戲是什麼」。遊戲設計在 `docs/design/`，主線規格在 `docs/superpowers/`。

| 檔案 | 內容 | 什麼時候更新 |
|---|---|---|
| `production-log.md` | 製作過程報告：每一輪做了什麼、為什麼、結果、對應的提交 | 每一輪工作結束時加一段 |
| `ai-collaboration.md` | AI 協作與分工介紹：角色、流程、規則，以及每次代理分工的實例 | 分工方式改變、或用了新的分工時 |
| `retrospective.md` | 檢討：做得好的、下次可以改進調整的地方 | 發現問題或每一輪結束時 |

**要拿來介紹時**：以這三份為正本，再另外做成簡報或網頁；不要直接改簡報而讓正本過時。

**寫法**：繁體中文、白話；日期、提交編號、數字寫清楚，方便日後引用。
