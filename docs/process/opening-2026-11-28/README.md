# 木馬之夜新開場截圖（2026-11-28，畫面）

使用者 11/28 選了「丙＋甲，再加鏡頭動畫」，依據是 `docs/design/2026-11-27-opening-and-tutorial.md`。這裡收截圖和量測腳本，截圖都是 1280×720，用 Chrome 無頭模式、靜音拍。

| 檔案 | 內容 |
|---|---|
| `0-標題-耳機與滑鼠提示.png` | 標題畫面：「戴上耳機」和「點一下畫面鎖滑鼠」從按鍵說明搬到開始鍵上面 |
| `1-序-黑底一次一句.png` | 序：黑底，一次只出一句，每句配一段聲音 |
| `2-腹中-跟著他敲.png` | 腹中第二步：校準搬進腹中，看起來是在跟著同伴敲木板 |
| `3-腹中-踩著它走到暗門.png` | 腹中第三步：預告圈和 4 格計數 |
| `cam-1-越過城門.png`、`cam-2-街上.png`、`cam-3-停在木馬前.png` | 鏡頭動畫（`?intro=cam`）：黃昏從城門外越過門頂、沿街走、天黑時停在木馬前 |

量測：
- `intro-time.mjs`：從按「開始」到走出木馬要多久，由程式玩家操作，序不按、讓它自己播。結果約 36～48 秒，低於 90 秒的目標。
- `intro-check.mjs`：檢查四種情況，分別是舊流程開關、短展示、新流程的 Esc 跳過、鏡頭動畫（截圖、幀數、只出現一次）。

用法：`ROOT=<prototypes 的路徑> node intro-time.mjs <輸出資料夾>`。
