# 夜晚模擬報告

由 `tools/NightSim` 產生：每種組合 200 場，種子 1。規則直接用 `Assets/Odyssey/Core`（巨人大腦、巨石、天亮、禱告、體力、聲音），空間是平面近似。

一場＝從 12 名同伴開始，一夜一夜玩到逃出或全滅（最多 12 夜）。

## 機器人策略

| 策略 | 怎麼玩 |
|---|---|
| 不動 | 原地不動，什麼都不做（基準線） |
| 猛衝 | 直接走去巨石，一路猛推到開（新手會做的事） |
| 謹慎 | 蹲著走、看不清就製造聲音、巨人靠近就停或退、輕推、塞楔子、他禱告時猛推 |
| 引開 | 「謹慎」再加上：巨人靠近巨石時射箭到他另一邊引開 |
| 帶人 | 「引開」再加上：先找最多 4 名同伴再去巨石（前 120 秒） |
| 彈弓引開 | 「謹慎」再加上：巨人靠近巨石時，用彈弓把石子射到他另一邊引開（不用箭） |
| 正面出手 | 「謹慎」再加上：巨人朝你逼近到 6 m 內時，用彈弓直接打他（宙斯法則判定） |
| 一招到底 | 「彈弓引開」但石子永遠射向同一個地方（洞西側）：確認巨人會學 |

機器人只知道「看到、聽到」的事：回聲照亮的範圍、離巨人 8 m 內（心跳與腳步）、同伴的嗚咽、禱告聲。

## 限制（看數字時要記得）

- 沒有模擬：羊與羊叫遮聲、羊圈、奶桶、乳酪架、木樁、地形高低、岩壁擋路；箭射出就不撿回。
- 機器人是寫死的策略，比真人笨也比真人準（反應零延遲、不會手滑）。看的是**趨勢和相對差距**，不是真人的確切勝率。
- 彈弓打中巨人的機率假設為 8 m 內 70%；雅典娜的眷顧（縫光）與手抖不影響機器人。
- 規格第 34 節：有模擬雷鳴耳鳴（A）與巨人會學（E，跨夜減半）；沒有模擬馬戎的酒、刻痕、雅典娜的點數與天亮前的反向剝奪。
