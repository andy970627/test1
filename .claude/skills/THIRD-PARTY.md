# 第三方技能來源

以下技能複製自 Matt Pocock 的 skills 集合（https://github.com/mattpocock/skills，MIT 授權），內容未修改，放進 repo 是為了讓雲端工作階段也能用：

- `diagnosing-bugs`：難查的 bug、效能退化
- `research`：查一手來源並存成帶引用的 md
- `grilling`：對計畫或設計逐題追問
- `handoff`：把對話壓成交接文件
- `writing-for-agents`：撰寫技能、CLAUDE.md 的指引
- `codebase-design`：深模組、介面與切分點的共用詞彙

本機版本在 `~/.claude/skills/`。上游或本機更新後，要手動同步這裡的副本。

`verify-odyssey`、`humanizer-zh` 是本專案自己的技能（`humanizer-zh` 改編自 blader/humanizer，MIT）。
