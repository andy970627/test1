# 繁體中文去 AI 腔

改寫自 [blader/humanizer](https://github.com/blader/humanizer)（MIT 授權）與維基百科 WikiProject AI Cleanup 的〈Signs of AI writing〉，改成適用繁體中文。

目的是讓文字自然、直接、好讀，不是規避偵測。不增減任何事實、數字、名稱、出處。

## 本專案先看這裡

遊戲內文字還要守 `docs/game-text.md` 第 0 節的風格規則（口吻、稱呼、標點、情境提示只描述不教做法）。兩者衝突時，第 0 節優先。吟遊詩人的詩句（第 31 節 D）可以有比喻和節奏，但仍要具體，不能空泛。

## 要找的痕跡

### A. 擺姿態，不直接說
1. **「不是 X，而是 Y」「與其說…不如說…」**：沒有人主張 X 時，直接說 Y。
2. **收尾金句、一連串短句**：「這，就是代價。」「黑暗。寂靜。等待。」刪掉重複的收尾，短句併成一句具體的話。
3. **假深刻的格言**：「真正的勇氣，是…」「有時候，…才是…」。換成具體的說法。
4. **鋪陳開場**：「值得一提的是」「讓我們來看看」「說到底」。刪掉，直接講。
5. **跟不存在的人爭論**：「你可能會以為…其實…」，文中沒人這樣以為就刪掉。

### B. 為了節奏硬湊
6. **硬湊三項**：「緊張、刺激、充滿挑戰」。內容真的有三件事才寫三件。
7. **同一個開頭連用**：連續幾句都用「你」「他」「這」開頭。合併或換主詞。
8. **破折號串句**：「——」「—」當連接詞。改成句號、逗號、冒號、括號或重寫。（本專案的情境提示禁止破折號。）
9. **層層保留**：「可能在某種程度上或許」。只留來源支持、意思需要的那一個。
10. **被動與沒有主詞**：「被認為」「被發現」，讓做事的人出來。

### C. 灌水與借權威
11. **AI 常用詞**：深刻、至關重要、不可或缺、見證、彰顯、賦能、獨特的、無與倫比、精心打造、沉浸式、旅程、篇章、交織、宛如一場…。換成平實的詞。
12. **誇大意義**：把普通的事說成「改變一切」「意義深遠」。留下事實，拿掉升華，結束在最後一個具體事實。
13. **空泛的關聯**：「與…息息相關」「象徵著」。說出真正的關係，說不出就刪。
14. **尾巴附加意義**：「…，展現了…」「…，體現出…」。來源沒說就刪。
15. **宣傳腔**：形容詞堆疊、推銷口吻。直接說它是什麼。
16. **借權威**：「專家指出」「眾所周知」。說出是誰，或刪掉。
17. **繞路動詞**：「作為…而存在」「扮演著…的角色」。用「是」「有」。

### D. 格式
18. **裝飾用粗體**、每個列表項目都加粗體標籤。只留真正需要的。
19. **裝飾性標題**：表情符號、箭頭、標題重複內容。標題要說出內容。

### E. 聊天與草稿殘留
20. **聊天機器人的開頭結尾**：「好的！」「希望這對你有幫助」「如果還有問題…」。刪掉外殼，留內容。
21. **知識截止聲明與猜測**：說清楚來源沒寫什麼，或刪掉。
22. **第一句重複標題**：刪。
23. **描述文件本身**：「本文將介紹」「以下整理了」。刪，除非是出處或會改變讀者行動的說明。

### F. 寫給錯的讀者
24. **重講讀者已知的背景**：先講結論，只留會改變讀者判斷的理由。

## 步驟

1. **標出痕跡**：讀完全文，從最明顯的開始標。
2. **改寫**：保留每個有根據的說法；不加來源或使用者沒給的事實、名稱、數字、日期、引文。
3. **檢查**：唸一遍，確認事實沒有增減，再找一次殘留，特別是 1、2、6、8、18。
4. **定稿**：用自然的話重說，不是逐詞替換；句子長短交錯。

## 語氣

有使用者的範文就照它的風格（包括標點習慣）。沒有時：說明與技術文字保持中性；遊戲內敘事照 `docs/game-text.md` 第 0 節。

## 輸出

- 貼上的文字：給改寫稿、還剩哪些痕跡、定稿。
- 檔案：只改文字，程式碼、路徑、`{X}` 這類佔位符、資料、連結一律不動。
- 遊戲字串：列成「原文／改成／理由」表，寫進 `docs/game-text.md` 讓使用者校正，確認後才改程式。
